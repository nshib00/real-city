# Варианты названия игры

## Правила подбора и оценки

1. Желательно подбирать простые, лаконичные англоязычные названия, хорошо описывающие суть игры.
2. Варианты с субъективной оценкой 0 в файле не хранятся и удаляются из списка.
3. Все критерии имеют одинаковый вес. Суммарная оценка — сумма заполненных оценок в строке.
4. Субъективная оценка — предпоследний столбец. Для новых вариантов он остаётся пустым, чтобы оценку поставил автор.
5. Объективные критерии оцениваются по шкале от 0 до 10. Оценки из первоначальной таблицы по шкале 1–5 переведены умножением на 2.
6. Варианты в таблице сортируются по суммарной оценке по убыванию. После изменения оценки таблицу нужно пересортировать.

Пока субъективная оценка не выставлена, сумма включает только объективные критерии. После её заполнения сумму нужно пересчитать.
