# Визуальная приёмка очереди 41–50

Дата: 30.10.2026. **Визуальный прогон не выполнен.** Vite не может открыть локальный порт в текущем окружении. Ниже зафиксированы подготовленные сценарии и остаток, а не результаты просмотра скриншотов.

## Подготовленные проверки

В `frontend/tests/e2e/ui.spec.ts` добавлена запись состояний карты с панелями, собственного профиля с показателями и пустого чата для 1440×900 и 390×844. Время профиля и данные зафиксированы, для снимков отключены CSS-анимации, дождались шрифтов; canvas и меняющийся индикатор соединения маскируются. Маска исключает карту из визуальной проверки, поэтому эти снимки проверяют только оболочку интерфейса. Дополнительно проверяется горизонтальная доступность окна профиля. CI сохраняет PNG-вложения и диагностику также при успешном прогоне.

Запуск: `cd frontend && node node_modules/playwright/cli.js test --config tests/e2e/playwright.config.ts`. Артефакты: `frontend/test-results`; для просмотра HTML выполнить `node node_modules/playwright/cli.js show-report`, если выбран HTML reporter. Это запись артефактов и проверки геометрии, а не сравнение с утверждёнными эталонами.

Компонентные тесты отдельно проверяют публичную карточку, сокрытие лишних полей, ошибку и повтор загрузки, сохранение формы после ошибки API, счётчики свёрнутой панели и чтение только видимого журнала. Они не подтверждают внешний вид в реальном браузере.

## Исправления, подтверждённые кодом и тестами

- Форма настроек больше не теряет введённое при периодическом обновлении профиля; ошибка сохранения видна игроку.
- В инспекторе есть переход к публичной карточке владельца; она выводит только явный список допустимых полей.
- Свёрнутая панель показывает суммарный индикатор, а журнал не читает события, пока скрыт.
- При смене аккаунта очищаются предыдущие события обороны.
