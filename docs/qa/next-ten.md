# Вторая очередь из десяти задач — 30.10.2026

Реализация и ограничения приёмки отражены в [плане](../plans/plan.md), строки 16.3, 19.2, 16.6, 11.7, 11.16, 11.17, 1.22, 1.18, 2.14/2.16, 19.5.

- Рынок сопоставляет встречные заявки по цене и времени; цена задаётся за исходный лот. Частичное исполнение допускается в количестве, сохраняющем целые монеты для обоих лимитов. Комиссия взимается при создании. Неисполненный резерв возвращается при отмене; улучшение цены возвращается покупателю. Вся сделка выполняется транзакционно.
- Казна считает баланс по полному ledger. Расход разрешён лидеру/казначею в пользу участника того же союза. Покупка баффа списывает `25 × level²` дерева. Каталог задаёт строительство 3%, ремонт 4%, добычу 2%, защиту 2% за уровень, максимум 5 уровней; общий предел эффекта 20%.
- Опыт ограничивается по серверным категориям действий и суткам UTC, с убывающей отдачей и общим дневным пределом. Audit сохраняет запрошенный и фактически начисленный XP, включая нулевые начисления; смена объекта не сбрасывает лимит категории.
- Профиль хранит avatar/banner/title, домашний центр и групповой контекст. Публичный ответ содержит агрегированные score и район размером 32 клетки; email, настройки, точные ресурсы и координаты центра не выдаются.
- Размер общего мира 160×160, чанка 32×32. Общие helpers нормализуют координаты, кратчайшие расстояния и списки чанков; footprint зданий проверяется и через шов мира.

## Проверки

`cd frontend && npm test` — 318/318 тестов в 76 файлах. `npm run build` — успешно. `npm run test:e2e:list` — два реальных сценария desktop/mobile. Playwright использует настоящий API и WS; размещение и добыча в текущем сценарии выполняются HTTP-командами после входа через UI, без mocks.

`python3 tools/check_contracts.py` сверяет маршруты/OpenAPI, размеры мира, события и поля публичного профиля. `bash scripts/check-contracts.sh` дополнительно запускает генераторы и Go-тесты. CI добавляет format/vet/race/build, PostgreSQL/Redis, повторное применение миграций и restart smoke.

В этом окружении Go отсутствует, Docker socket недоступен (`permission denied`), сетевые сокеты запрещены. Поэтому серверная сборка, миграции, SQL/race и живой E2E не подтверждены. Разбор Go исходников форматтером не заменяет компиляцию. Непроверенные строки плана остаются частичными. При доступном окружении: `cd backend && go run ./cmd/migrate up`, затем `go test -race ./...`; из корня `bash scripts/test-gameplay-local.sh`; для браузера поднять API и выполнить `cd frontend && npm run test:e2e`.
