# Жилой небоскреб

Жилой небоскреб - поздняя стадия плотной городской ветки.

## Роль

- высшая стадия ветки Каменный дом -> Многоквартирный дом -> Жилой небоскреб;
- максимизирует население на клетку;
- показывает современную позднюю Эолию.

## Визуальный стиль

- вертикальный силуэт;
- светлые современные материалы;
- стекло, башенные секции, мягкие магические огни;
- аккуратные технические детали без перегруза карты;
- должен быть заметным ориентиром, но не перекрывать соседние тайлы настолько, чтобы мешать управлению.
