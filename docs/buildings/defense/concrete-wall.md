# Название defense-постройки

Шаблон для башен, стен, ворот, пушек, ловушек и защитных объектов.

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `defense` |
| Подтип | башня / стена / ворота / пушка / ловушка / другое |
| Footprint | не задано |
| Расходует лимит построек | да / нет / не задано |
| Первый уровень строится напрямую | да / нет / не задано |
| Требует гарнизон / рабочих | да / нет / не задано |
| Может атаковать игроков | да / нет / не задано |
| Может атаковать монстров | да / нет / не задано |
| Условия работы | не задано |
