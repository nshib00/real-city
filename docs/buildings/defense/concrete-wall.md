## Действующие награды XP

Источник: `backend/internal/domain/catalog/building_xp.json`. Эта таблица имеет приоритет над прежними проектными числами XP ниже в документе.

Награда за создание/апгрейд выдаётся владельцу после успешного завершения, по итоговому типу и уровню. Это одна награда, а не сумма наград за начало и конец действия. При переходе к другому типу используется таблица нового типа.

XP за уничтожение чужой постройки получает игрок, нанёсший последний удар оружием, или создатель добившего монстра. Урон без уничтожения, снос своего здания, дикие монстры и повторная обработка награду не дают.

Работа — один сбор урожая/продукции; суперурожай даёт тройной XP. Ноль означает отсутствие отдельной награды за работу. Ремонт, перенос, отмена, перезарядка и переключение защиты отдельно XP не дают; защитные убийства диких монстров сохраняют свою награду.

Среднеигровой участок периметра после каменной стены: массивный бетонный сердечник и металлическая арматура обозначают защиту производственных кварталов. Не атакует и не заменяет орудия. Цены, время и HP уровней соответствуют действующему каталогу; влияние стены на маршрут монстров пока не подтверждено pathfinding.

## Системные свойства

| Свойство | Правило |
| --- | --- |
| ID / категория | `concrete_wall` / `defense` |
| Место в ветке | глобальные уровни 8–10, переход после каменной стены 7-го уровня; после 10-го — современная стена |
| Размещение | секция 1×1 на свободной сухой клетке; при переходе типа занятая своей стеной клетка сохраняется |
| Стыковка | четыре ортогональных направления; `single`, `end`, `straight`, `corner`, `t`, `cross` по соседям |
| Лимит и население | отдельный оборонный слот не расходует; строители по таблице заняты до завершения работ, постоянного гарнизона нет |
| Бой | атак и радиуса нет; стена блокирует проход согласно общим правилам коллизии |
| Владение | улучшать, чинить и сносить может только владелец; чужие игроки только просматривают |

Стоимость строки — плата за переход **на этот уровень**, а не накопленная цена ветки. Для перехода с камня на бетон также списывается полная стоимость уровня 8; прямую покупку бетонной стены не открывать.

## Визуальный сеттинг и состояния

Основание строго внутри ромба клетки; высота не должна визуально перекрывать передние секции неправильным порядком. Секции разных форм стыкуются без щелей. Игровое семейство `concrete_wall_l08`…`l10` содержит все 16 форм стыковки и состояния `active`, `construction`, `damaged`, `ruined`. У разрушенной стены отдельная низкая модель с обломками. Клиент выбирает модель по уровню, форме и состоянию из `frontend/public/assets/buildings/roads/concrete_wall/`.

При выборе карта подсвечивает HP и владельца. Только владельцу доступны улучшение/снос; во время апгрейда сервер удерживает строительное население и не освобождает клетку для второго объекта. Снос возвращает 20% фактически уплаченных монет за уровни по общему правилу, материалы не возвращает.
