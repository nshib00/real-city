## Системные свойства

| Свойство | Значение |
| --- | --- |
| ID / категория | `defense_guardian_enclosure` / `defense`, база защитников |
| Footprint | 1×1 сухой свободной клетки; один слот капитальной обороны |
| Открытие | поздняя цепочка трав/редких материалов; не повышает урон игроку напрямую |
| Функция | создание, приписка и восстановление существ: `bramble_guard` и `moss_mender` |
| Лимит | активных существ на 1 вольер — по таблице; не более половины слотов — лекари, округление вниз, минимум 1 при двух слотах |
| Радиус патруля | расстояние от вольера по клеткам из таблицы; центр назначается владельцем внутри радиуса; при погоне нельзя выйти за радиус |
| Население | 1 постоянный смотритель; без него новые существа не создаются и существующие переходят в режим возвращения/ожидания |
| Ресурсы | при создании существа однократно списываются ресурсы из его спеки; на патруле регулярных затрат нет |
| Повреждение/разрушение | при HP <25% создание и лечение останавливаются; при разрушении приписанные существа выключаются и исчезают после безопасного завершения текущего тика без дропа |
| XP | за стройку/апгрейд/разрушение не задано; XP за убийство дикого монстра приписывается владельцу один раз |

## Визуальный сеттинг и состояния

Вольер — природно-индустриальное убежище, а не клетка для пленного монстра: дерево, плетень, зелёные ткани, каменные борта, кормушки и лечебные лотки. Все детали и выступы укладываются в ромб основания; силуэт с каждым уровнем растёт, но остаётся узнаваемой ограждённой площадкой. Пять разных моделей `defense_guardian_enclosure_l01`…`l05`; состояния `construction`, `active`, `no_keeper`, `damaged`, `ruined`. Анимации существ создаются отдельными объектами, не «запекаются» в модель здания.

## UI и серверная логика

Владелец видит HP, слот, состав отряда, здоровье и патруль каждого существа, стоимость/время создания, смотрителя и причину простоя. Чужие игроки видят собственника, общий состав и HP без команд/лечения. Создание проверяет владение, свободный слот, ресурсы, здоровье базы, смотрителя и место появления; повтор команды не создаёт клона. Мёртвое существо не возрождается автоматически: требуется новое создание. После сноса 20% суммарно потраченных на уровни монет возвращаются, стоимость существ и материалов — нет.
