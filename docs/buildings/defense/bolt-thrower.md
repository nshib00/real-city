## Действующие награды XP

Источник: `backend/internal/domain/catalog/building_xp.json`. Эта таблица имеет приоритет над прежними проектными числами XP ниже в документе.

Награда за создание/апгрейд выдаётся владельцу после успешного завершения, по итоговому типу и уровню. Это одна награда, а не сумма наград за начало и конец действия. При переходе к другому типу используется таблица нового типа.

XP за уничтожение чужой постройки получает игрок, нанёсший последний удар оружием, или создатель добившего монстра. Урон без уничтожения, снос своего здания, дикие монстры и повторная обработка награду не дают.

Работа — один сбор урожая/продукции; суперурожай даёт тройной XP. Ноль означает отсутствие отдельной награды за работу. Ремонт, перенос, отмена, перезарядка и переключение защиты отдельно XP не дают; защитные убийства диких монстров сохраняют свою награду.

Орудие средней стадии точного огня: бьёт одиночных быстрых монстров без расхода инвентарных боеприпасов, зато уступает пушке по разовому урону. Числа ниже подключены к игре и ожидают проверки баланса в плейтестах.

## Игровая роль и правила

| Свойство | Значение |
| --- | --- |
| ID / категория | `defense_bolt_thrower` / `defense`, орудие |
| Footprint | 1×1, свободная сухая проходимая клетка, один слот капитальной обороны |
| Работа | 1 житель постоянного гарнизона; 1 `piercing`-выстрел в 1 дикого монстра раз в 5 секунд; боеприпасов нет |
| Прицел | ближайший монстр в радиусе и прямой видимости; затем меньшие HP, затем ID |
| Выключение | стройка, апгрейд, отсутствие гарнизона, HP ниже 25% |
| PvP и лут | не атакует игроков/их защитников/здания; лут убитого монстра остаётся публичным |
| XP | за стройку/апгрейд/разрушение не задано; XP за убийство — владельцу по общей формуле один раз |

В строке указана стоимость **перехода** на уровень; время занятости строителей не равно времени занятости гарнизона.

## Визуальный сеттинг, состояния и UI

Рама и длинное плечо всегда читаются с изометрической камеры; поворотная голова не выходит основанием за ромб клетки. Палитра: тёмное дерево, выбеленная тетива, железные скобы; позднее каменный цоколь, латунные детали привода. Восемь отдельных моделей `defense_bolt_thrower_l01`…`l08`, каждая с элементом из таблицы. Состояния `construction`, `active`, `no_crew`, `damaged`, `ruined`; анимация натяжения и короткий видимый болт без перекрытия соседей. Карточка владельца показывает HP, радиус, DPS, cooldown, гарнизон и последнюю цель; чужим доступен только просмотр.

Сервер подтверждает владение при апгрейде/включении, свободную клетку, жителя, LOS, таймер и уникальность события выстрела. Снос — 20% уплаченных монет за все уровни без возврата материалов; при разрушении житель гарнизона освобождается.
