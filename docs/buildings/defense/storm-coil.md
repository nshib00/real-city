Орудие поздней средней стадии против бронированных монстров. Даёт редкий сильный импульс с расходом бензина; уязвимо без промышленной цепочки электроники. Числа ниже подключены к игре и ожидают проверки баланса в плейтестах.

## Игровая роль и правила

| Свойство | Значение |
| --- | --- |
| ID / категория | `defense_storm_coil` / `defense`, орудие |
| Footprint | 1×1, свободная сухая клетка, один слот капитальной обороны |
| Выстрел | один `shock`-импульс по ближайшему дикому монстру каждые 15 секунд, только при прямой видимости |
| Эффект | урон из таблицы + задержка следующей атаки монстра на 2 секунды, без бесконечного стана: повторный импульс только обновляет таймер |
| Гарнизон и топливо | 1 постоянный житель; 1 бензин на выстрел, атомарное списание; без бензина простаивает |
| Отключение | апгрейд/стройка, HP <25%, отсутствие жителя или топлива |
| PvP/XP | только дикие PvE-монстры; XP за постройку/апгрейд/разрушение не задано, за убийство — владельцу один раз |

## Визуальный сеттинг, состояния и UI

Каменное основание в пределах 1×1, медно-тёмная вертикальная обмотка, приглушённый голубой разряд только при работе. Для каждого уровня отдельная модель `defense_storm_coil_l01`…`l06` с видимым изменением из таблицы. Не копировать привычные тесла-башни: силуэт — промышленный столб с концентрическими кольцами. Состояния `construction`, `active`, `no_fuel`, `no_crew`, `damaged`, `ruined`. Карточка владельца: HP, радиус, урон, cooldown, бензин, гарнизон, цель; чужому игроку — только параметры и владелец.

Сервер авторитетен для LOS, целей, таймера, списания топлива, урона и эффекта задержки. Дебафф хранит `expires_at` и не стакается. При сносе возвращается 20% монет за все уровни, материалы и использованный бензин не возвращаются.
