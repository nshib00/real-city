Стационарная артиллерия ранней игры против диких монстров. Дорогой выстрел и длинная перезарядка компенсируются высоким уроном. Это капитальная оборонная постройка, а не переносимый предмет/оружие игрока. Все числа ниже внесены в игру; общие правила — в [плане обороны](../../game-design/defense-expansion-plan.md).

## Игровая роль и системные свойства

| Свойство | Правило |
| --- | --- |
| ID / категория | `defense_cannon` / `defense` |
| Footprint | 1×1, только свободная сухая проходимая клетка; 1 капитальная постройка на клетку |
| Стройка/лимит | 1-й уровень строится напрямую; расходует 1 слот оборонных зданий; лимит слотов — не задано |
| Цели | только живые дикие PvE-монстры; дружественный огонь и PvP отсутствуют |
| Гарнизон | 1 житель на всех уровнях, пока пушка включена; при нехватке свободного населения не включается |
| Выстрел | прямая видимость; 1 выстрел в одну цель каждые 12 секунд; `explosive`-урон, без урона по площади |
| Боеприпас | уровни 1–6: 1 `stone` за выстрел; уровни 7–12: 1 `explosives` за выстрел, списывается атомарно вместе с уроном; при отсутствии — статус «Нет зарядов» |
| Автоатака | ближайшая цель в радиусе, затем минимальные HP, затем ID; нельзя стрелять по клетке вне радиуса |
| Работа | стройка/апгрейд, HP <25%, отсутствие гарнизона или боеприпаса отключают атаку |
| XP | за строительство/апгрейд/уничтожение — не задано; за убийство дикого монстра — один раз владельцу по общей формуле |

Уровень `n` покупается за стоимость **строки n**. Время и жители в таблице относятся к стройке/апгрейду; строительный наряд освобождается после завершения, постоянный гарнизон считается отдельно. Цены и боевые числа требуют плейтеста против [HP монстров](../../game-design/monster-specs.md).

## Визуальный сеттинг и состояния

Основание полностью вписано в ромб 1×1; ствол выступает вверх, но не переносит точку сортировки на соседнюю клетку. Материалы: состаренная древесина → каменный постамент → тёмный металл с бирюзовыми/медными техническими вставками. Каждый из 12 уровней имеет отдельную модель и указанный в таблице узнаваемый новый элемент; профиль «ствол на лафете» остаётся постоянным. Избегать реалистичных современных военных маркировок и копирования исторических орудий.

Модели: `defense_cannon_l01`…`l12`; состояния `construction`, `active`, `idle_no_ammo`, `damaged`, `ruined`. При выстреле короткий откат и вспышка, без затенения соседних объектов; разрушение не оставляет работающий ствол. Для UI: владелец видит уровень, HP, радиус, урон, cooldown, гарнизон, количество зарядов, цель и причину простоя; остальные — только владельца, HP и основные параметры, без кнопок управления. Радиус показывать при выборе, попадание и расход патрона — в журнале событий.

## Серверные проверки

Сервер проверяет владение при апгрейде/включении/сносе, свободную клетку, ресурсы, жителей, линию огня и ID живой цели. Выстрел, списание боеприпаса текущего уровня, урон и событие смерти проходят одной транзакцией. После рестарта нельзя повторить старый выстрел или лут; offline-симуляция ограничена реальными боеприпасами. Собственный снос возвращает 20% суммарно уплаченных монет по общему правилу, материалы не возвращает.
