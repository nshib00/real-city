Оборонная мастерская финальной стадии для будущей сборки патрульных роботов. Цены, уровни, HP, число слотов и радиус внесены в игровой каталог; создание и патруль роботов пока проектные. Роботы задуманы отдельными сущностями, не постройками, и не должны давать добычу при уничтожении.

## Системные свойства

| Свойство | Значение |
| --- | --- |
| ID / категория | `defense_automaton_bay` / `defense`, база защитников |
| Footprint | 1×1 свободной сухой клетки, один слот капитальной обороны |
| Функция | сборка `clockwork_sentinel` и `repair_wisp`, приписка к базе, ремонт в мастерской |
| Лимит | активные роботы по таблице; ремонтных — не более половины слотов (округление вниз) |
| Радиус | от клетки мастерской по таблице, включая назначенный центр патруля |
| Население | 1 механик постоянно; при его отсутствии роботы возвращаются на базу и не сражаются |
| Создание | стоимость и время каждого робота — в [каталоге защитников](../../game-design/player-defenders.md); сборка только при свободном слоте |
| Топливо | 1 бензин за каждые 10 минут активного патруля **каждого** робота; в ожидании на базе не расходуется |
| Повреждение | ниже 25% HP новая сборка и ремонт блокируются; уничтожение базы выключает приписанных роботов, без лута |
| XP | за стройку/апгрейд/разрушение не задано; за убийство дикой цели — владельцу по общей формуле, один раз |

## Визуальный сеттинг и состояния

Индустриальное здание с низким каменным цоколем, тёмным металлом, медными проводниками и матовым светом; с карты должны читаться манипуляторы и сборочные рамы. Избегать современных логотипов и узнаваемых франшизных роботов. Пять моделей `defense_automaton_bay_l01`…`l05`, каждое улучшение отдельной геометрией. Состояния `construction`, `active`, `no_mechanic`, `no_fuel`, `damaged`, `ruined`; маленькие движущиеся роботы — отдельные сущности карты.

## UI и серверная логика

Карточка владельца: HP, активные роботы, их здоровье и патруль, топливо, очередь сборки/ремонта, механик, заблокированные причины. Чужим — только просмотр. Сервер валидирует слот, владение, свободную стартовую клетку, ресурсы и сборочный таймер; один запрос/ID задачи — один робот. Ремонт происходит только у базы, расходует 1 инструмент и 2 железных слитка на каждые 100 восстановленных HP, с округлением вверх; не воскресает из нулевого HP. Собственный снос возвращает 20% монет за все уровни мастерской, но не за роботов, ремонт, топливо или материалы.
