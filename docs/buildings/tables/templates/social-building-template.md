# Название social-постройки

Шаблон для союзных, общественных, дипломатических и групповых зданий.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `social` |
| Подтип | союз / гильдия / общественный центр / дипломатия / другое |
| Footprint | не задано |
| Расходует лимит построек | да / нет / не задано |
| Первый уровень строится напрямую | да / нет / не задано |
| Кто может построить | любой игрок / лидер / офицер / не задано |
| Уникальность | одна на игрока / одна на союз / несколько / не задано |
| Что открывает | союз, чат, роли, казна, пожертвования, баффы, цели, не задано |
| Уязвимость для рейдов | да / нет / не задано |
