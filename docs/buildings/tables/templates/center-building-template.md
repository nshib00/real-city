# Название center-постройки

Шаблон для ратуши, управляющих зданий, административных центров и построек, которые открывают системные лимиты.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `center` |
| Уникальность | одна на игрока / одна на карту / несколько / не задано |
| Footprint | не задано |
| Расходует лимит построек | да / нет / не задано |
| Первый уровень строится напрямую | да / нет / не задано |
| Стартовая постройка | да / нет / не задано |
| Что открывает | строительство, лимит, территория, исследования, союзы, не задано |
| Зона влияния / территория | не задано |
| Уязвимость для рейдов | да / нет / не задано |
