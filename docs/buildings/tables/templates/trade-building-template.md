# Название trade-постройки

Шаблон для рынков, торговых площадок, монетных и обменных зданий.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `trade` |
| Подтип | рынок / обмен / аукцион / монетный бонус / другое |
| Footprint | не задано |
| Расходует лимит построек | да / нет / не задано |
| Первый уровень строится напрямую | да / нет / не задано |
| Открывает торговлю между игроками | да / нет / не задано |
| Требует дорогу / склад / центр | да / нет / не задано |
| Уязвимость для рейдов | да / нет / не задано |
