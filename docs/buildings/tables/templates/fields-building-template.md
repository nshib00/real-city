## Визуальная идентичность культуры

Каждая fields-постройка должна иметь собственный стиль основания, а не только другую растительность поверх одинаковой грядки. В описании модели укажи:

- профиль основы из библиотеки: `windleaf`, `flax`, `seed`, `mushroom`, `herb`, `reed` или новый профиль;
- материал бортика и столбов;
- рисунок досок, камней или рядов;
- 2-4 узнаваемых props, которые относятся именно к этой культуре;
- чем уровни апгрейда меняют основание, а не только высоту растений.

Для генерации использовать `fields.add_styled_bed_base`, `fields.add_bed_post`, `fields.add_bed_board` или специализированный профиль той же логики. Нельзя использовать один и тот же plank/log bed для всех грядок без уникальных признаков культуры.

| --- | --- |

| Когда бросается шанс редкой итерации | при посадке / после сбора / при завершении роста / не задано |
| Offline progress | не задано |
