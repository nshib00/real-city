# Название industry-постройки

Шаблон для производственных, добывающих и перерабатывающих построек: заводов, мастерских, карьеров, шахт, нефтяных объектов и похожих зданий.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `industry` |
| Подтип | добыча / переработка / мастерская / завод / топливо / другое |
| Footprint | не задано |
| Расходует лимит построек | да |
| Первый уровень строится напрямую | да / нет / не задано |
| Открывается после | не задано |
| Улучшается в другой тип | не задано |
| Предпочтительное окружение | дорога / склад / лес / вода / ресурсный узел / не задано |
| Ограничения размещения | не задано |
| Уязвимость для атак | да / нет / не задано |
| Что останавливает работу | стройка, повреждение, нет ресурсов, нет топлива, нет рабочих, переполнен склад, не задано |

## Состояния и UI

| Нужные состояния модели | `active`, `construction`, `damaged` |

| Offline progress | не задано |
| Поведение при повреждении во время цикла | не задано |
