# Название roads-постройки

Шаблон для дорог, мостовых, мостов и логистической инфраструктуры.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `roads` |
| Подтип | дорога / мост / логистический узел / другое |
| Footprint | не задано |
| Расходует лимит построек | обычно нет |
| Первый уровень строится напрямую | да / нет / не задано |
| Апгрейды внутри типа | да / нет / не задано |
| Автостыковка с соседями | да / нет / не задано |
| Разрешено протягивание цепочкой | да / нет / не задано |
| Ограничения размещения | не задано |

## Варианты формы

| Вариант | Когда используется | Особенности визуала |
| --- | --- | --- |
| `single` | нет соседей | не задано |
| `end_n/e/s/w` | один сосед | не задано |
| `straight_ns/ew` | два противоположных соседа | не задано |
| `corner_ne/es/sw/wn` | два соседних направления | не задано |
| `t_nes/esw/swn/wne` | три направления | не задано |
| `cross` | четыре направления | не задано |

## Состояния и UI

| Поле | Значение |
| --- | --- |
| Нужные состояния модели | `active`, `construction`, `damaged` |
| Что показывать в карточке | тип дороги, стоимость, бонус, HP, отсутствие/наличие апгрейда |
| Что показывать на карте | предпросмотр цепочки, корректные повороты, повреждение, разрыв сети |
| Пересчет соседей | серверное состояние плюс клиентский предпросмотр |
| Что происходит при разрушении | не задано |
