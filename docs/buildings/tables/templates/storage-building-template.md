# Название storage-постройки

Шаблон для складов, хранилищ монет, топливных резервуаров и лимитных вместилищ.

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | не задано |
| Категория | `storage` |
| Подтип | материалы / монеты / топливо / редкости / общий склад / другое |
| Footprint | не задано |
| Расходует лимит построек | да / нет / не задано |
| Первый уровень строится напрямую | да / нет / не задано |
| Что хранит | не задано |
| Влияет на глобальный или локальный лимит | глобальный / локальный / оба / не задано |
| Уязвимость для атак | да / нет / не задано |
