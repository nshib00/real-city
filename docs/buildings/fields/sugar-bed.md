# Сахарная грядка

Сахарная грядка выращивает `sugar_cane`. Это mid-game культура, близкая к Тростниковой грядке по вертикальности, но более дорогая и торговая. Она должна читаться теплее и суше: толстые сочные стебли, светлые срезы, сладкие узлы и корзины для нарезанного сырья.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | `sugar_bed` |
| Категория | `fields` |
| Культура / основной ресурс | `sugar_cane` |
| Footprint | 1x1 |
| Расходует лимит построек | да |
| Первый уровень строится напрямую | да |
| Игровой этап | mid-game |
| Количество уровней | 9 |
| Плановая стоимость 1 уровня | 125 000 монет |
| Открывается после | Тростниковая грядка 4 уровня или пищевая цепочка 2 уровня |
| Что останавливает рост | стройка, сильное повреждение, нет рабочих, нет семян |

## Игровая роль

Сахарная грядка - пищевая и торговая культура среднего этапа. Она потребляет семена, доски, тростник, ткань, глину и позднее металл, потому что игрок улучшает плотность посадки, подвязку, сбор толстых стеблей и хранение сладкого сырья.

## Ресурсная прогрессия

- Уровни 1-3: семена, доски, тростник, ткань и глина задают mid-game вход.
- Уровни 4-6: кирпичи, каменные блоки, премиум-доски и синяя соль показывают укрепление влажной, но теплой грядки.
- Уровни 7-9: железо, золото и супер-семя усиливают торговую ценность культуры.
- `sugar_cane` уже есть в иконках ресурсов; перед включением в производство его нужно добавить в общий каталог ресурсов.

## Визуальный стиль для 3D-модели

Основание - теплая земля с толстыми вертикальными стеблями. Отличие от Тростниковой грядки: стебли крупнее, палитра желто-зеленая, меньше водных канавок, больше светлых срезов и корзин. Борта растут от простого дерева до глиняно-каменной рамки.

### Уникальная геометрия и декор

- Форма стен: высокий прямоугольник с округленными глиняными углами и открытым рабочим вырезом на одной стороне. Это не водная ванна: земля сухая и теплая, а стенки выглядят как укрепленный торговый короб для тяжелых стеблей.
- Опоры: толстые сахарные стойки-пилоны из дерева и глины, обмотанные широкой веревкой. На поздних уровнях опоры получают светлые керамические накладки и маленькие золотистые торговые пломбы.
- Декор на стенах: светлые срезы стеблей, подвязанные пучки, плоские керамические таблички с геометрическим знаком капли сиропа, мешочки у входного выреза. Узоры теплые: охра, светлая глина, muted gold.
- Декор вокруг: корзины нарезанного сырья, связки толстых стеблей, тканевые мешки, мерная чашка, короткая разделочная доска. Общие мешки и корзины можно брать из библиотеки, но стебли и светлые срезы должны быть собственными.
- Уникальные элементы: глиняный округлый угол борта, сахарный пилон с широкой обмоткой, пучок толстых стеблей со светлыми срезами, торговая пломба на борту, доска для рубки стеблей.
- Не использовать: тонкие холодные тростниковые колья, прессовую механику Масличного поля, аптекарские стеклянные колпаки, кристальные плоды.

| Уровни | Внешний вид |
| --- | --- |
| 1-2 | Низкие толстые ростки, деревянная рамка, теплая земля. |
| 3-4 | Средние стебли, веревочные перевязки, первые срезанные пучки. |
| 5-6 | Выше борта, глиняные вставки, корзины и плотные ряды. |
| 7-8 | Каменные края, тканевые мешки, несколько срезанных светлых стеблей. |
| 9 | Высокие укрепленные борта, богатая зрелая посадка, золотистые торговые акценты. |

## Стадии роста

| Стадия | Визуал |
| --- | --- |
| 1 | Короткие толстые ростки. |
| 2 | Стебли до половины высоты борта. |
| 3 | Плотные вертикальные стебли с перевязками. |
| 4 | Зрелая сахарная культура, видны срезы и корзины. |

## Состояния модели

| Состояние | Требования к модели |
| --- | --- |
| Строительство | Пустая теплая земля, лежащие стебли и доски. |
| Рабочее состояние | Стебли должны быть толще и теплее по цвету, чем у `reed_bed`. |
| Повреждение | Поломанные стебли, рассыпанные срезы, поврежденные борта. |
| Разрушение | Остатки сухих стеблей и почти пустая земляная площадка. |
