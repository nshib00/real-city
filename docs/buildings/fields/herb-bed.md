# Травяная грядка

Травяная грядка - mid-game полевая постройка для выращивания `herbs` и редкого урожая `rare_flowers`. Визуально это мягкая аптекарская грядка: невысокие плетеные борта, пучки зелени, маленькие бирки растений и все более аккуратная травяная геометрия на поздних уровнях.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | `herb_bed` |
| Категория | `fields` |
| Культура / основной ресурс | `herbs` |
| Редкий урожай | `rare_flowers` |
| Footprint | 1x1 |
| Расходует лимит построек | да |
| Первый уровень строится напрямую | да |
| Игровой этап | mid-game |
| Количество уровней | 9 |
| Плановая стоимость 1 уровня | 75 000 монет |
| Открывается после | Семенной огород 6 уровня, базовая алхимия или травничество |
| Что останавливает рост | стройка, сильное повреждение, нет рабочих, нет семян для посева |

## Игровая роль

Травяная грядка закрывает переход от базовых семян к лечебным и ремесленным растениям. Это уже не стартовая грядка: она входит в mid-game, поэтому с 1 уровня требует обработанные материалы, ткань и ремесленные компоненты. `herbs` используются в рецептах усилений, восстановления и красителей, поэтому стоимость должна заметно отставать от ранних полей.

## Ресурсная прогрессия

- Уровни 1-3: доски, ткань, кирпичи и ветролист задают mid-game вход вместо стартовой посадки.
- Уровни 4-6: каменные блоки, премиум-доски, железо и синяя соль добавляют защищенные сушильные секции.
- Уровни 7-9: редкие цветы, изумрудная пыль и супер-семя превращают грядку в дорогой аптекарский участок.
- `rare_flowers` пока используется как проектный ресурс из набора иконок; перед внедрением баланса его нужно синхронизировать с `shared/catalog/resources.ts`.

## Визуальный стиль для 3D-модели

Травяная грядка должна отличаться от Семенного огорода мягкой зеленью и аптекарскими деталями. Основание - округлая земляная площадка с плетнем из тонких прутьев. Борта растут постепенно: от низкой деревянно-тканевой рамки на 1 уровне до укрепленной аптекарской грядки на 9 уровне.

### Уникальная геометрия и декор

- Форма стен: скругленный прямоугольник с мягкими дугами по углам, без жесткой квадратной геометрии. Стены собираются из плетеных лозовых панелей, а на поздних уровнях получают низкий каменный цоколь и тонкие резные деревянные верхние планки.
- Опоры: тонкие раздвоенные стойки-веточки с веревочными узлами. Они должны отличаться от обычных колышков: верх стойки слегка расходится буквой `Y`, чтобы держать сушильные жердочки и бирки.
- Декор на стенах: маленькие аптекарские бирки без текста, пучки сушеных трав, тканевые полоски приглушенного teal/cream и простые листовые орнаменты на верхней планке. На 7-9 уровнях добавить 2-3 стеклянных колпачка для редких ростков.
- Декор вокруг: низкая сушильная рамка, мини-лейка, глиняный кувшин, лоток для семян и полка для бирок. Эти элементы можно брать из общей библиотеки, но расставлять асимметрично, чтобы модель не выглядела как Семенной огород.
- Уникальные элементы: аптекарский `Y`-столбик, полукруглый плетеный сегмент стены, стеклянный колпачок редкого цветка, связка трав на раздвоенной стойке.
- Не использовать: высокие водные канавки тростника, яркие пигментные секции Красильного сада, металлические прессовые детали Масличного поля.

| Уровни | Внешний вид |
| --- | --- |
| 1-2 | Низкий плетень, рыхлая земля, несколько зеленых пучков без строгой сетки. |
| 3-4 | Появляются бирки растений, больше пучков, тонкие веревочные подвязки. |
| 5-6 | Борта выше, добавлены сушильные жердочки и небольшие тканевые ленты. |
| 7-8 | Каменные уголки, плотные ряды трав, несколько редких цветков как акцент. |
| 9 | Декоративные узоры на бортах, маленькие стеклянные колпачки и заметный редкий цветок в центре. |

## Стадии роста

| Стадия | Визуал |
| --- | --- |
| 1 | Темная земля, редкие ростки и несколько меток посадки. |
| 2 | Низкая зелень покрывает треть грядки. |
| 3 | Плотные травяные кустики, видны разные оттенки листьев. |
| 4 | Готовая трава с цветущими верхушками и редкими яркими точками. |

## Состояния модели

| Состояние | Требования к модели |
| --- | --- |
| Строительство | Пустая земляная форма, лежащие прутья, часть борта не собрана. |
| Рабочее состояние | Четкая читаемость пучков травы сверху и с изометрической камеры. |
| Повреждение | Сломанные секции плетня, примятая зелень, темные пятна земли. |
| Разрушение | Остатки лозы, сухие пучки, почти пустая земляная площадка. |
