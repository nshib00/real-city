# Масличное поле

Масличное поле выращивает `oil_plants` - mid-game растительное сырье для масла, еды, ремесла и будущей химии. Важно визуально не путать его с нефтяной промышленностью: это теплая сельскохозяйственная культура с желто-зелеными головками, корзинами семян и простыми прессовыми деталями на поздних уровнях.

## Общие параметры

| Параметр | Значение |
| --- | --- |
| Внутренний тип / id | `oilseed_field` |
| Категория | `fields` |
| Культура / основной ресурс | `oil_plants` |
| Footprint | 1x1 |
| Расходует лимит построек | да |
| Первый уровень строится напрямую | да |
| Игровой этап | mid-game |
| Количество уровней | 7 |
| Плановая стоимость 1 уровня | 260 000 монет |
| Открывается после | Семенной огород 7 уровня, базовое пищевое производство и ремесленная переработка |
| Что останавливает рост | стройка, сильное повреждение, нет рабочих, нет семян |

## Игровая роль

Масличное поле - дорогая mid-game ступень между обычными полями и переработкой. Оно должно потреблять много семян, обработанного дерева, каменных блоков и металла, потому что игрок строит не только посадку, но и сушку, сбор, хранение и первичное давление масличных головок.

## Ресурсная прогрессия

- Уровни 1-3: семена, доски, ткань, каменные блоки и железо сразу ставят поле в mid-game.
- Уровни 4-5: премиум-доски и механизмы добавляют сушильные стойки, сборники и простую прессовую механику.
- Уровни 6-7: золото, большое количество железа и супер-семя показывают дорогую культивацию на границе late-game.
- `oil_plants` уже есть среди ресурсных иконок; перед экономикой его нужно добавить в общий каталог ресурсов.

## Визуальный стиль для 3D-модели

Основание - сухая теплая грядка с золотистыми и зелеными растениями. Главное отличие от Сахарной и Тростниковой грядок: культура ниже и шире, с круглыми семенными головками. Борта растут от низкой деревянной рамки до каменно-деревянного основания с маленькими прессовыми деталями.

### Уникальная геометрия и декор

- Форма стен: восьмиугольная сухая грядка с короткими скошенными углами. Силуэт должен отличаться от прямоугольных полей и круглых садов: углы заняты корзинами, сушильными стойками или каменными башмачками.
- Опоры: толстые деревянные стойки с металлическими кольцами, похожие на крепления для ручного пресса. На 4-7 уровнях появляются маленькие вертикальные винтовые стойки и поперечины для сушки головок.
- Декор на стенах: семенные диски, небольшие масляные капли на темных деревянных вставках, железные уголки, плоские желто-охристые орнаменты без букв. Декор должен намекать на масло, но не на нефтяную промышленность.
- Декор вокруг: корзины семян, низкая сушильная рамка, рабочий столик сортировки, мерная чашка, небольшой прессовый рычаг у борта. Общие корзины и лотки можно брать из библиотеки; прессовый рычаг и винтовую стойку нужно сделать уникальными.
- Уникальные элементы: восьмиугольный сухой борт, стойка ручного пресса, семенная головка-диск, корзина масличных головок, мини-желоб для масла.
- Не использовать: водные каналы тростника, сладкие срезы сахарной грядки, цветные пигментные лотки, стеклянные тепличные панели.

| Уровни | Внешний вид |
| --- | --- |
| 1-2 | Редкие зеленые ростки, несколько желтых головок, низкие борта. |
| 3-4 | Больше рядов, веревочные подвязки, первые корзины для семян. |
| 5-6 | Сушильные рейки, плотные желтые пятна, каменные углы. |
| 7 | Прочные каменные края, маленькие металлические детали пресса, яркая зрелая культура. |

## Стадии роста

| Стадия | Визуал |
| --- | --- |
| 1 | Зеленые ростки и сухая земля. |
| 2 | Низкие кусты с первыми желтыми бутонами. |
| 3 | Развитые растения с видимыми семенными головками. |
| 4 | Зрелое поле с корзинами семян и плотными золотистыми пятнами. |

## Состояния модели

| Состояние | Требования к модели |
| --- | --- |
| Строительство | Пустая сухая грядка, лежащие доски и корзины. |
| Рабочее состояние | Желтые головки читаются как культура, а не как декоративные цветы. |
| Повреждение | Сломанные сушильные рейки, рассыпанные семена, примятые растения. |
| Разрушение | Сухая земля, остатки корзин, редкие сломанные стебли. |
