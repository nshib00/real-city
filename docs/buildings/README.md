# Постройки Real City

Документация по постройкам вынесена из общего файла сеттинга в отдельные категории. Общий сеттинг, карта, ресурсы, руины, персонажи и UI остаются в `docs/visual-style-and-setting-options.md`.

## Категории

- `center/` - центральные и управляющие здания.
- `houses/` - жилые постройки и ветки населения.
- `fields/` - поля, грядки и растительные производственные объекты.
- `industry/` - заводы, мастерские и переработка ресурсов.
- `roads/` - дороги и логистика.
- `social/` - союзные и общественные постройки.
