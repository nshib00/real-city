## Общие правила и границы реализации

### Отрасли без утверждённого игрового типа или выпуска

Это пробелы ресурсной цепочки, а не доступные постройки. До присвоения нового `building_id` и уровня они не должны появляться в меню строительства.

| Пробел | Ближайший игровой объект | Что требуется для рабочей спеки |
| --- | --- | --- |
| Добыча угля и железной руды | `mine`, `iron_mine` | Утвердить источник узла/тайла, выход по уровням, время, работников, истощение и конкуренцию за месторождение. У обоих пока нет выпуска, закрывающего цепочку. |
| Выпуск инструментов и железных слитков | `forge`, `foundry` | Слитки производит литейная; кузница уже расходует готовые слитки на метательные клинки. Для выпуска инструментов нужен отдельный рецепт без циклической цены открытия. |
| Верёвка и медные детали | `rope_yard`, `mechanical_workshop` | Закрепить вход льна/волокна и меди, минимальный уровень, топливо и реальную доступность до первого обязательного апгрейда. |
| Золотой слиток | нового типа нет | Выбрать источник золотой руды или редкого выхода, переработчик, стоимость и лимит выпуска; не подменять `coins`. |
| Супер-механизм и эолиевый сплав | нового типа нет | Задать редкие ингредиенты, источник каждого, производственный уровень, шанс или гарантированный выпуск и тест достижимости поздних цен. |

Для будущего ID нужна та же полная спека, что для действующих 36 типов: footprint, строительство по уровням, вход/выход и единицы измерения, работники, бензин, длительность, местное/глобальное хранение, остановка, разрушение, UI и визуальные состояния. Добавление записи в каталог без достижимого источника ингредиентов не закрывает этот пробел.

- Строительство: сервер проверяет ратушу, свободную клетку, лимит, цену, число строителей и таймер. Для `oil_well` действует специальное правило редкой нефтяной клетки; обычный `industry`-объект туда не ставится.
- Производственный запуск: только зарегистрированный рецепт на допустимом уровне. Входы, рабочие, `FuelPerRun`, длительность, гарантированный и редкий выход берутся из серверного рецепта; UI не вычисляет награду по текстовой проектной таблице.
- Если входов, бензина или работников не хватает, запуск отклоняется до списания; один объект не запускает конкурирующие циклы. Офлайн-таймер продолжает отсчитываться сервером, результат выдаётся единожды.
- Материалы хранятся в общем инвентаре игрока. У производственного здания пока нет локального складского лимита; дорога пока не является обязательной и не ускоряет выпуск. Остановка из-за полного локального склада и транспортный штраф — будущие правила.
- Повреждение, разрушение и ремонт проверяются по общим серверным состояниям. Если документ описывает иной штраф или редкий выход, он считается проектным до появления рецепта/теста. Не включать проектный эффект лишь на клиенте.
- Для каждой отсутствующей отрасли нужно сначала выбрать источник входов без ресурсного тупика, затем задать поуровневый рецепт, worker/fuel/time, сохранение job, редкие шансы и тест на повтор команд. После этого обновить индивидуальную спеку и UI.

## Приёмка категории

Сверить все 36 игровых ID и каждый существующий уровень: цена, время, строители, HP, доступность рецепта, вход, выход, редкий шанс, топливо и серверная причина простоя. Выполнить цикл: добыть сырьё → запустить переработку → дождаться → собрать → повредить/восстановить → повторить после reconnect; ни одна стадия не должна выдавать награду дважды.
