# Заводы и мастерские

Производственные здания превращают природные материалы в более ценные ресурсы:

- [Лесопильный двор](sawmill-yard.md): дерево -> доски, редкие премиум-доски;
- [Песчаный карьер](sand-quarry.md): добыча песка, монеты, редкая синяя соль;
- кирпичная печь: глина + уголь -> кирпич;
- стекольная мастерская: песок + уголь -> стекло;
- кузница: руда + уголь -> слитки, инструменты;
- ткацкий двор: волокно -> ткань, веревки;
- красильня: красители + ткань -> флаги, товары;
- механическая мастерская: слитки + медь -> механизмы;
- оптическая мастерская: стекло + светокристаллы -> линзы;
- Нефтеперерабатывающий завод: нефть -> бензин;
- монетный двор: монеты.

Нефтеперерабатывающий завод - специальный завод для переработки нефти в бензин. Визуально это компактное светлое промышленное здание с резервуарами, трубами, колонной переработки, бочками и аккуратной анимацией пара или огней. На ранней стадии бензин может быть не нужен, но большинство заводов на средних и поздних апгрейдах должны потреблять бензин для работы или ускоренного производства.

Заводы должны быть визуально активными: небольшая анимация дыма, колеса, света, подъемника, труб, резервуаров или рабочих деталей, но без перегруза карты.
