# Проверки качества и подготовка выпуска

## Локальные команды

`bash scripts/check-quality.sh` запускает полный барьер: версия Go, gofmt без изменения файлов, vet, race-тесты, сборка команд, существующая проверка контрактов, frontend typecheck, тесты и production build. Отсутствие Go завершает команду ошибкой. `bash scripts/check-quality.sh frontend` явно проверяет только клиент. Команда `npm run lint` пока является TypeScript-проверкой: отдельные ESLint/formatter этой работой не добавлены.

CI frontend дополнен typecheck и `npm audit --omit=dev --audit-level=high`. Уязвимости production-зависимостей high/critical блокируют этот job, включая отсутствие ответа registry. Dev-зависимости и Go требуют отдельных проверок; полный security gate пока не готов. Нельзя обходить ошибку через `continue-on-error`. Если требуется исключение, сначала сохранить пакет, advisory, обоснование, владельца, компенсирующую меру и срок окончания; автоматического механизма исключений сейчас нет.

## Локальные образы

`bash scripts/build-release-local.sh` требует чистое дерево Git и доступный Docker daemon, собирает backend и frontend с тегом полного commit SHA и OCI revision. Не выполняет login/push, миграции или deploy. Сохраняет `artifacts/release/images.json`; старый манифест удаляется перед сборкой, новый появляется только после успешной сборки обоих образов. Локальный image ID — digest конфигурации образа, а не digest registry manifest. Статус явно сообщает об отсутствии сканирования и развёртывания.

Сканирование ОС и зависимостей, SBOM, provenance и registry digest ещё нужно добавить. Для внешней публикации требуется отдельное поручение. После сканирования использовать существующую изолированную репетицию `scripts/test-production-local.sh`; возврат к предыдущим образам выполняется `scripts/test-production-rollback.sh` только на совместимой схеме. Не запускать rollback миграций ради возврата приложения. Наличие подготовленного скрипта не является успешной репетицией.

## Подготовленная защита

Backend-образ устанавливает CA и запускает API/worker/migrate как UID/GID 10001. Production Compose запрещает повышение привилегий, сбрасывает capabilities и делает root filesystem backend доступной только для чтения; `/tmp` ограничен 16 MiB. Для миграций остаётся необходимым чтение `/app/db/migrations`, запись должна идти в PostgreSQL.

Caddy закрывает `/metrics` и `/debug` с подмаршрутами на публичном origin, запрещает iframe и доступ к камере/микрофону/geolocation, ограничивает тело API-запроса 1 MiB. Доступность private API, Origin/token/WS, таймауты, HTTPS и здоровье контейнеров ещё требуют изолированной проверки. Backend не публикует порт на host. Web/Caddy пока не переведён на non-root: его сертификаты, writable volumes и порты нужно проверить отдельно.

Секреты `.env*`, приватные ключи и PEM исключены из контекста сборки (шаблон `.env.example` разрешён). Это не заменяет сканирование образа и аудит файлов других форматов.
