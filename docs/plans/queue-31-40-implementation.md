- `command -v go` и поиск `*/bin/go` в `/usr`, `/opt`, `/home/nshib` не нашли Go toolchain.
- `curl -I --max-time 10 https://go.dev`: `Could not resolve host: go.dev`.
- `docker info`: `permission denied` при обращении к `/var/run/docker.sock`.
- `command -v psql`: исполняемый файл отсутствует.
- `npm run dev -- --host 127.0.0.1`: `listen EPERM 127.0.0.1:5173`; Playwright останавливается при запуске webServer.

1. Выполнить backend CI и `TEST_POSTGRES_DSN=... bash scripts/test-migration-upgrade.sh` только с отдельной тестовой БД. Сохранить серверные JSONL и миграционный отчёт; устранить реальные ошибки, затем расширить недостающие SQL-матрицы из пунктов 33–37.
2. Выполнить live desktop/mobile CI и проверки на реальном мобильном устройстве. После исправления ошибок получить нагрузочные показатели пункта 39 по фиксированному профилю.
3. Выполнить ручной production-rehearsal workflow с образами конкретного предыдущего релиза либо локально задать `REAL_CITY_PREVIOUS_BACKEND_IMAGE`, `REAL_CITY_PREVIOUS_FRONTEND_IMAGE` и запустить `bash scripts/test-production-local.sh`. Доступ к registry и свободные порты 80/443 должны быть подготовлены. `REAL_CITY_SKIP_ROLLBACK=1` разрешает только smoke и оставляет пункт 40 открытым.

Схема 48 с искусственными данными проверяет конкретный путь обновления, но не заменяет прогон на копии существующей игровой БД. Откат кода по новой схеме и восстановление dump — отдельные проверки; их нельзя выдавать за полную репетицию несовместимого отката.
