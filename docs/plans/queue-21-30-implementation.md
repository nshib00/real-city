## Ограничения

Go toolchain отсутствует, DNS не разрешает `go.dev`, Docker socket возвращает `permission denied`, локальный порт Vite запрещён (`EPERM`). Поэтому Go/SQL/race, миграции, фактический XP, нагрузка, развёртывание и восстановление остаются неподтверждёнными. Отчёты об успешных прогонах не подменяются подготовленными скриптами.
