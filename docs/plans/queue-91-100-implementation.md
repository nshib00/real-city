## Воспроизведение

```sh
bash scripts/check-quality.sh frontend

# Нужны Go 1.24, psql и Python 3; оба адреса должны вести на тестовый стенд.
TEST_POSTGRES_DSN='postgres://real_city:real_city@127.0.0.1:15432/real_city?sslmode=disable' \
TEST_REDIS_ADDR='127.0.0.1:16379' bash scripts/test-storage-integrations.sh

# Нужны свободные порты 80/443 и Docker. Проект и тома удаляются после прогона.
REAL_CITY_SKIP_ROLLBACK=1 \
REAL_CITY_ACCEPTANCE_ARTIFACTS=/tmp/real-city-acceptance-91-100 \
bash scripts/test-production-local.sh
```

Локальный Go отсутствует, поэтому SQL-тесты фактически запущены в одноразовом `golang:1.24-alpine` с `bash`, `postgresql-client`, `python3`, доступом к опубликованным тестовым портам и теми же переменными. Первый вариант контейнерной установки пакетов прерывался из-за сетевого сбоя Alpine; после подготовки локального образа с инструментами тест прошёл. Вспомогательный образ не является частью проекта.

Повторный успешный production-прогон сохранил `compose.log`, `http.jsonl`, `ws.jsonl`, `rollback.json` и `result.json` в `/tmp/real-city-acceptance-91-100-rerun`. Финальный `result.json` содержит `{"status":"passed","last_stage":"complete","exit_code":0,"rollback":"skipped"}`. Контейнеров `real-city-acceptance-*` после прогона нет. Временные игровые checkpoint-файлы с токенами удалены сценарием.

Короткие контрольные замеры внутри репетиции: обычный viewport — 374 ответа 200, 124,44 RPS, p95 8,99 мс; смешанные запросы — 323 ответа 200, 107,51 RPS, p95 37,15 мс; швы — 661 ответ 200, 219,96 RPS, p95 10,85 мс. Ошибок HTTP нет. WS — 8 соединений, 16 доставок, реконнект, 0 отказов, p95 24,73 мс. Окна 3–4 секунды и малый мир; эти цифры не являются нагрузочной или мобильной приёмкой.

## Открытые требования

- При паузе PostgreSQL `/ready` не всегда возвращает 503 до клиентского таймаута. Нужен отдельный разбор ограничений драйвера/pool и бюджетов деградации; данная очередь не меняет серверную семантику вслепую.
- Проверка совместимости с настоящими образами предыдущего релиза и откат не выполнены: образы не заданы. `REAL_CITY_SKIP_ROLLBACK=1` намеренно не выдаётся за её прохождение.
- Нет проверки внешнего домена и публичного сертификата, graceful shutdown, длительной нагрузки, клиентского FPS и полного desktop/mobile сценария в браузере. SQL-тесты покрывают конкретные репозитории, а не все возможные гонки игрового цикла.
