## Команды воспроизведения

```sh
# Для миграционного скрипта нужны Go, psql, bash и Python внутри одноразового
# контейнера с доступом к тестовой PostgreSQL; TEST_POSTGRES_DSN указывает на неё.
bash scripts/test-migration-upgrade.sh

REAL_CITY_SMOKE_X=44 REAL_CITY_SMOKE_Y=45 python3 tests/e2e/api/gameplay_restart.py --prepare /tmp/real-city-state.json
docker compose -p real-city-test -f docker-compose.test.yml -f docker-compose.laptop.yml restart backend
python3 tests/e2e/api/gameplay_restart.py --verify /tmp/real-city-state.json

bash scripts/check-contracts.sh
python3 scripts/record-observability-baseline.py --base-url http://127.0.0.1:18080 --seconds 6 --workers 4
```

Для `measure-realtime.py` использован новый тестовый аккаунт и его токен только в памяти процесса; токен не сохранён в отчёте. Параметры: `--base-url http://127.0.0.1:18080 --seconds 10 --connections 10` и затем `50`, `--reconnect-rounds 1`. Временные файлы restart-сценария с токенами удалены после проверки.

## Границы результата

WS-клиенты использовали один тестовый аккаунт, обычный общий чат и короткое окно; 100/1000 независимых игроков, медленный читатель и длительный разрыв сети не проверены. HTTP использовал прогретые повторяющиеся URL, а не непрерывно меняющуюся камеру; p95 и RPS нельзя переносить на холодный населённый мир. Нет новых CPU/heap-профилей AI, мобильных кадровых замеров, полного цикла production backup/restore и отката на предыдущий образ. Эти требования остаются открытыми в очередях 31–40 и фазе 26.
