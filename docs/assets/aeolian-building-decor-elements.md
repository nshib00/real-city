# Декоративные элементы зданий Эолии

Документ описывает 100 декоративных элементов, которые можно добавлять на здания Real City. Цель - расширить библиотеку деталей для `tools/assets/blender/real_city/components/` так, чтобы новые модели выглядели как яркая эолийская fantasy mid-poly диорама, а не как набор простых примитивов.

## Общие правила моделирования

- Делать детали крупнее реалистичного масштаба на 10-25%, если иначе они пропадают в изометрии 512x384.
- Использовать bevel на видимых ребрах: `0.01-0.04` для малых props, `0.04-0.08` для камня/балок/крупных рам.
- Материалы именовать по роли: `MAT_wood_pale`, `MAT_wood_dark`, `MAT_rope_warm`, `MAT_metal_worn`, `MAT_copper_clean`, `MAT_crystal_amethyst`, `MAT_cloth_teal`.
- Деталь должна физически касаться опоры: стены, крыши, стойки, земли, пола или соседнего элемента.
- Для повторяемых элементов держать origin в точке крепления к зданию: центр планки, основание стойки, задняя плоскость таблички, центр петли.
- Для LOD1 удалять мелкие крепежи и сокращать цилиндры до 8-10 сегментов; для LOD2 оставлять только силуэт и 1-2 цвета.
- В production-скриптах использовать общие helpers из `tools/assets/blender/real_city/geometry.py`, `materials.py` и существующих `components/*`, не копировать camera/export helpers.

## Крыши, карнизы и верхние силуэты

1. **Ветровой флюгер-лист**
   - Задача: маленький вертикальный маркер для домов, ратуш, рынков и башен.
   - Моделирование: стойка из тонкого цилиндра 8-10 вершин, сверху плоский stylized лист из 5-7 вершин или вытянутый ромб. Добавить маленькую втулку-шар между стойкой и листом. Лист повернуть под 15-25 градусов, чтобы он читался в изометрии.
   - Материалы: темное железо для стойки, зеленая патинированная медь или приглушенный teal для листа. LOD1 - стойка и один лист без втулки.

2. **Мини-ветроколесо**
   - Задача: передать мотив ветра на поздних и ремесленных постройках.
   - Моделирование: центральная ось-цилиндр, 4 лопасти из тонких вытянутых box/frustum с мягким bevel, лопасти слегка выгнуть дугой через 2-3 сегмента или поворот отдельных пластин. Ставить на фронтон, башенку или стойку.
   - Материалы: `wood_pale` для ранних уровней, `metal_worn` + `copper_clean` для поздних. Не делать больше 0.35 м по диаметру на 1x1 здании.

3. **Изогнутый конек крыши**
   - Задача: сделать обычную двускатную крышу эолийской.
   - Моделирование: вдоль конька поставить тонкую балку из цилиндра/beam, по концам добавить поднятые загнутые наконечники из коротких наклонных балок. Края должны слегка выступать за крышу, но не менять footprint.
   - Материалы: дерево, черепица или темный металл по типу крыши. LOD1 - только основная балка и два наконечника.

4. **Козырек с тканевой лентой**
   - Задача: оживлять входы и боковые окна.
   - Моделирование: маленькая наклонная крыша из box/frustum, две треугольные боковые опоры, снизу 1-2 тонкие ленты как плоские меши с волнистым нижним краем.
   - Материалы: крыша в цвет здания, ленты `cloth_teal`, `cloth_red` или `cloth_cream`. Ленты делать достаточно широкими, не тоньше 0.04 м.

5. **Деревянные торцевые накладки**
   - Задача: подчеркивать дощатые крыши деревянных домов.
   - Моделирование: на торце крыши разместить 3-5 отдельных планок с разной длиной и микросмещениями по z. Между планками оставить швы 0.01-0.02 м. Добавить 2-3 круглые шляпки гвоздей как маленькие диски.
   - Материалы: чередовать `wood_pale`, `wood_warm`, `wood_dark`; гвозди `metal_worn`. LOD1 - слить планки в один объект с материалными полосами.

6. **Рунная черепичная вставка**
   - Задача: отличать здания с рунической черепицей.
   - Моделирование: на основной крыше сделать узкую полосу из 3-7 плиток, каждая плитка - beveled box с легким наклоном по скату. На 1-2 плитках добавить неглубокий рунный знак как отдельная тонкая светлая геометрия, не текст.
   - Материалы: `roof_rune_tile_blue`, `roof_rune_tile_green`, руны `stone_light` или слабый amethyst. Не использовать сильное свечение.

7. **Подвесной фонарь под карнизом**
   - Задача: теплый жилой/городской акцент.
   - Моделирование: крючок из двух коротких цилиндров, подвесная цепочка 2-3 маленьких звена или один темный шнур, корпус фонаря как маленький шестигранный цилиндр с рамкой.
   - Материалы: `metal_worn`, стекло `glass_warm`, внутри маленький `emissive_amber` с низкой силой. LOD1 - корпус и шнур без звеньев.

8. **Каменный водосток-носик**
   - Задача: добавить полезную архитектурную функцию на каменные здания.
   - Моделирование: короткий наклонный желоб из box/frustum, конец сделать открытым U-образным силуэтом тремя прямоугольниками. Крепить к краю крыши, направлять от стены.
   - Материалы: `stone_warm` или `metal_worn`; добавить темную внутреннюю плоскость. LOD1 - простой наклонный блок.

9. **Крышевая гребенка из дощечек**
   - Задача: декоративная мелкая ритмика на ранних домах.
   - Моделирование: 5-9 коротких вертикальных дощечек вдоль конька, каждая с bevel и разной высотой. Концы слегка скруглить bevel modifier.
   - Материалы: теплое дерево, на поздних уровнях - темная полированная древесина. Не ставить на каждую крышу, чтобы не было шума.

10. **Малый дымник с ветровым колпаком**
    - Задача: узнаваемый верхний силуэт жилья и мастерских.
    - Моделирование: труба из квадратного или шестигранного сечения, сверху короткая стойка и плоский наклонный колпак. Добавить 1-2 металлических обруча вокруг трубы.
    - Материалы: кирпич/камень для трубы, темное железо для колпака. Для damaged state колпак можно наклонить, но труба должна иметь опору.

## Фасады, стены и окна

11. **Глубокая деревянная оконная рама**
    - Задача: сделать окно встроенным, а не наклеенным.
    - Моделирование: сначала создать темную нишу в плоскости стены или отдельный углубленный rectangle, затем 4 рейки рамы с bevel. Стекло поставить на 0.01-0.02 м глубже передней плоскости рамы.
    - Материалы: `wood_dark`, `glass_cyan`. Для LOD1 стекло и раму можно объединить, но сохранить темную нишу.

12. **Круглое иллюминаторное окно**
    - Задача: добавить сказочный ремесленный характер.
    - Моделирование: торус или кольцо из 16-20 сегментов, стекло как тонкий круглый диск, две перекладины крестом. Крепить на фронтонах, башнях, каменных домах.
    - Материалы: дерево/металл для кольца, `glass_bluegreen`. Для массовых объектов 12-14 сегментов достаточно.

13. **Оконные ставни с ветровой прорезью**
    - Задача: эолийский мотив без магии.
    - Моделирование: две ставни по бокам окна, каждая из 2-3 планок. В верхней планке сделать прорезь-каплю или спираль отдельной светлой накладкой, а не boolean.
    - Материалы: дерево с контрастной кромкой. Ставни должны касаться стены задней гранью.

14. **Полукруглая каменная арка окна**
    - Задача: усилить каменные и городские здания.
    - Моделирование: арка собирается из 5-7 клиновидных блоков вокруг верхней части окна. Каждый блок слегка отличается размером, но внутренний контур остается ровным.
    - Материалы: `stone_light`, швы темнее. LOD1 - один изогнутый/ступенчатый блок без отдельных камней.

15. **Вертикальная дощатая обшивка**
    - Задача: сделать деревянную стену читаемой как доски.
    - Моделирование: 5-9 узких beveled boxes на поверхности стены, разная ширина и легкие перепады глубины. Не оставлять щели, через которые видна пустота, если это целая стена.
    - Материалы: 2-3 оттенка дерева, темные швы. Для поздних зданий заменить на elite planks.

16. **Элитная полированная панель**
    - Задача: поздние деревянные здания выглядят богаче.
    - Моделирование: крупная ровная панель с тонкой внешней рамкой, внутри 1-2 диагональные декоративные планки и маленькие металлические заклепки.
    - Материалы: `premium_wood`, теплый edge highlight, заклепки `copper_clean` или `metal_worn`.

17. **Каменная кладка из крупных блоков**
    - Задача: читаемая каменная стена на игровом масштабе.
    - Моделирование: не делать мелкую сетку. Использовать 4-8 крупных блоков на фасад, разный размер, bevel 0.02-0.04, легкие z-offset по глубине.
    - Материалы: теплый серый камень, темные швы, местами мох маленькими плоскостями.

18. **Кирпичный декоративный пояс**
    - Задача: показать кирпич без перегруза.
    - Моделирование: горизонтальный пояс из 6-10 прямоугольников или один длинный box с material slots/цветовыми секциями. Размещать между этажами или под крышей.
    - Материалы: приглушенный красно-оранжевый, отдельные кирпичи темнее. LOD1 - единая полоса.

19. **Металлическая усиливающая скоба**
    - Задача: показать ремонт, индустрию или поздний апгрейд.
    - Моделирование: U- или L-образная скоба из 2-3 прямоугольных beams на углу стены. Добавить крупные болты-диски.
    - Материалы: темное железо, слегка светлая кромка. Не использовать на ранних бедных домах слишком часто.

20. **Фасадная табличка мастерской**
    - Задача: показать назначение без текста.
    - Моделирование: маленькая доска/камень на кронштейне; на поверхности добавить символ ресурсной цепочки: моток веревки, лист, молоток, мешок, капля масла. Символ делать геометрией из простых shapes.
    - Материалы: дерево/камень, символ контрастный. Не писать буквенные надписи.

## Двери, входы и пороги

21. **Дощатая дверь с поперечиной**
    - Задача: базовый вход ранних зданий.
    - Моделирование: 3-5 вертикальных досок, две горизонтальные поперечины, ручка-кольцо. Дверь ставить в нишу, чтобы не торчала из стены.
    - Материалы: дерево, темные швы, ручка `metal_worn`. LOD1 - цельная дверь с одной поперечиной.

22. **Каменная дверь-арка**
    - Задача: вход для каменных домов, хранилищ, башен.
    - Моделирование: темная арочная ниша, вокруг 5-9 блоков. Дверное полотно может быть плоским деревянным или металлическим внутри арки.
    - Материалы: теплый камень, дерево/железо для полотна. Следить, чтобы нижний край двери касался порога.

23. **Металлическая усиленная дверь**
    - Задача: поздние индустриальные и storage-здания.
    - Моделирование: прямоугольное полотно, 2 вертикальные ребра, 2 горизонтальные полосы, крупные заклепки. Добавить маленькое смотровое окно как темный inset.
    - Материалы: `metal_worn`, ребра чуть светлее, заклепки `iron_dark`.

24. **Порог из каменных плит**
    - Задача: связать дверь с ground-клеткой.
    - Моделирование: 2-4 плиты разной ширины перед входом, bevel 0.02, высота 0.04-0.07 м. Плиты должны лежать на земле без зазора.
    - Материалы: `stone_light`, мох/пыль как маленькие плоскости у краев.

25. **Деревянная мини-лестница**
    - Задача: вход на поднятый фундамент или крыльцо.
    - Моделирование: 2-4 ступени, каждая шире предыдущей снизу. Добавить боковые косоуры тонкими балками. Не делать слишком высоко для 1x1 footprint.
    - Материалы: дерево; для damaged state одну ступень можно повернуть и положить на землю.

26. **Кованая ручка-кольцо**
    - Задача: крупная читаемая дверная деталь.
    - Моделирование: torus 12-16 сегментов или кольцо из кривой bevel_depth, крепежная шайба-диск, маленький штырь. Размещать на высоте 0.45-0.65 двери.
    - Материалы: темное железо, светлый edge highlight.

27. **Навесной замок**
    - Задача: storage, ворота, поздние дома.
    - Моделирование: корпус как beveled box, дужка как U из кривой/цилиндров. Делать крупно, но не больше 0.12-0.16 м на двери.
    - Материалы: железо или латунь. LOD1 - корпус и простая U-дужка.

28. **Входной коврик из ветролиста**
    - Задача: мягкий эолийский бытовой акцент.
    - Моделирование: тонкая плоская прямоугольная сетка/box, поверх 3-5 широких листовых shapes с параллельным направлением. Кладется на ground перед дверью.
    - Материалы: темно-зеленый + светлые жилки. Не использовать там, где вход промышленный или ruined.

29. **Боковая подпорка входа**
    - Задача: усилить конструктивную логику козырька/крыльца.
    - Моделирование: диагональная beam от стены к нижней части козырька, второй короткий вертикальный упор. Концы должны реально касаться опор.
    - Материалы: дерево/металл по уровню здания.

30. **Дверная шторка из ткани**
    - Задача: рынки, мастерские, полевые постройки.
    - Моделирование: верхняя планка и 2-3 вертикальные тканевые полосы с разной длиной, внизу небольшой изгиб через наклон/деформацию плоскости.
    - Материалы: `cloth_cream`, `cloth_teal`, `cloth_red`; использовать roughness высокий.

## Балки, крепления и строительная логика

31. **Диагональная ветровая распорка**
    - Задача: эолийская тема устойчивости на ветру.
    - Моделирование: beam между стойкой и стеной под углом 35-55 градусов, на концах маленькие накладки/болты. Использовать на навесах, вышках, крыльцах.
    - Материалы: дерево для ранних, металл для поздних. В damaged state распорку ломать только если есть опора обломка.

32. **Веревочная стяжка**
    - Задача: связать дерево, поля, канаты и раннюю индустрию.
    - Моделирование: 2-3 тонких цилиндра/curves вокруг балки или между двумя стойками; узел как маленький шар/короткий torus. Диаметр не ниже 0.018 м.
    - Материалы: теплый rope, темный rope для повреждений. LOD1 - одна толстая стяжка.

33. **Медная втулка балки**
    - Задача: поздний ремесленный апгрейд.
    - Моделирование: короткий цилиндр или кольцо вокруг оси/балки, 12-16 сегментов, bevel. Добавить маленькую заклепку сбоку.
    - Материалы: `copper_clean`, roughness 0.45-0.6, без яркого блеска.

34. **Накладная железная пластина**
    - Задача: ремонт/усиление стен, дверей, механизмов.
    - Моделирование: тонкий beveled box, 2-4 болта, легкий поворот на поверхности. Пластина должна повторять угол фасада.
    - Материалы: темное железо, местами rust-brown через отдельные маленькие пятна.

35. **Деревянный кронштейн с вырезом**
    - Задача: поддерживать вывески, фонари, навесы.
    - Моделирование: L-образная конструкция из вертикального и горизонтального beams плюс диагональ. Вырез передавать не boolean, а светлым декоративным треугольником/вставкой.
    - Материалы: дерево, на поздних зданиях premium wood.

36. **Каменный угловой замок**
    - Задача: подчеркнуть углы каменных и кирпичных зданий.
    - Моделирование: 3-5 чередующихся блоков на углу, каждый выступает на 0.03-0.06 м. Не делать мелкую кладку.
    - Материалы: `stone_light` с темными швами. LOD1 - одна вертикальная ребристая полоса.

37. **Плетеная оградная вставка**
    - Задача: декоративный дворик, фермы, поля.
    - Моделирование: 3 вертикальные стойки и 4-6 горизонтальных тонких прутьев, прутья чередуют перед/за стойкой. Все сегменты должны касаться или слегка пересекаться.
    - Материалы: светлая лоза/дерево. LOD1 - 2 стойки и 2 рейки.

38. **Крепежный болт крупного масштаба**
    - Задача: читаемые точки сборки.
    - Моделирование: маленький цилиндр 8-12 сегментов, сверху граненый диск/шестигранник. Использовать инстансы для повторов.
    - Материалы: iron/copper/gold по уровню. Не ставить десятки болтов на один малый фасад.

39. **Петля ворот**
    - Задача: двери, ворота, складские створки.
    - Моделирование: две прямоугольные пластины и цилиндр-шарнир между ними. Шарнир должен выступать сбоку створки.
    - Материалы: железо; для элитных зданий - темное железо с латунной шайбой.

40. **Строительная метка уровня**
    - Задача: аккуратно показать апгрейд без UI-текста.
    - Моделирование: маленькие 1-3 насечки/плашки на балке или камне; число насечек можно увеличивать по уровню. Формы - короткие тонкие boxes.
    - Материалы: светлая краска/резьба. Использовать умеренно, чтобы не превратить модель в интерфейс.

## Флаги, ткани и ветровые мотивы

41. **Узкий флажок на шесте**
    - Задача: вертикальный силуэт и принадлежность здания.
    - Моделирование: шест цилиндром 8 вершин, флаг как плоскость из 4-6 вершин с волнистым свободным краем. Верх флага крепить к шесту без зазора.
    - Материалы: `cloth_teal`, `cloth_red`, `cloth_cream`; шест дерево/металл. LOD1 - прямоугольная плоскость.

42. **Двойная ветровая лента**
    - Задача: легкий мотив ветра на рынках и башнях.
    - Моделирование: две длинные узкие плоскости от общей планки, разные длины, каждая с 2-3 сегментами и небольшими поворотами. Не использовать physics sim для production.
    - Материалы: ткань с edge highlight. Длина не должна закрывать окна/двери.

43. **Тканевый навес-парус**
    - Задача: торговые, ремесленные, портовые или полевые здания.
    - Моделирование: 4 стойки или 2 стойки + стена, ткань как слегка провисшая плоскость из 6-9 вершин. Углы ткани должны совпадать со стойками.
    - Материалы: светлая ткань, веревочные растяжки. LOD1 - плоский наклонный quad.

44. **Малый настенный вымпел**
    - Задача: фасадная вертикаль без большого флага.
    - Моделирование: верхняя рейка, треугольная или раздвоенная ткань. Толщина через solidify 0.005-0.01 или тонкий box.
    - Материалы: ткань, символ ресурса/гильдии как простая накладка.

45. **Веревочная гирлянда с кистями**
    - Задача: праздничный/социальный декор.
    - Моделирование: основная веревка curve/beam между двумя точками, 3-5 кистей из коротких тонких плоскостей/цилиндров, кисти свисают вниз.
    - Материалы: rope + цветная ткань. Использовать для tavern/market/civic, не для шахт и разрушений.

46. **Знак ветра-спираль**
    - Задача: фирменная, но редкая эолийская эмблема.
    - Моделирование: спираль собрать из 4-6 коротких curved beams или плоских сегментов по дуге. Не делать идеальную тонкую линию; форма должна быть толстой и читаемой.
    - Материалы: дерево/камень/металл; для магических зданий слабый amethyst.

47. **Полосатая тканевая обвязка колонны**
    - Задача: оживить стойки и башенки.
    - Моделирование: 2-3 тонких кольца/ленты вокруг цилиндра, можно имитировать прямоугольными сегментами. Добавить маленький свободный хвост ткани.
    - Материалы: контрастная ткань, без сильной насыщенности.

48. **Парусный козырек окна**
    - Задача: заменить обычный деревянный козырек на эолийский.
    - Моделирование: маленькая тканевая плоскость между двумя штырями над окном, нижний край немного провисает. Штыри соединить со стеной.
    - Материалы: ткань + дерево/металл. LOD1 - треугольный навес.

49. **Тканевая заплата на крыше**
    - Задача: ранние и damaged-state здания.
    - Моделирование: тонкая плоскость/box, повторяющая скат крыши, 2-4 крепежа по углам. Края неровные через 6-8 вершин.
    - Материалы: грубая ткань, веревочные крепления. Не закрывать всю крышу.

50. **Подвесной знак с лентами**
    - Задача: городские и торговые здания.
    - Моделирование: кронштейн, подвесная табличка, снизу две короткие ленты. Табличка может иметь символ ресурса без текста.
    - Материалы: дерево/металл + ткань. LOD1 - табличка без лент.

## Свет, кристаллы и магико-технические акценты

51. **Аметистовый световой кристалл**
   - Задача: редкий премиум/руинный/магико-технический акцент.
   - Моделирование: вытянутый шестигранный кристалл: центральный prism 6 вершин + верхняя/нижняя пирамидальные крышки. Поставить в металлическую или каменную оправу.
   - Материалы: `crystal_amethyst` с небольшим emission, оправа `metal_worn` или `stone_light`. Не использовать на обычных ранних домах.

52. **Кристальная линза в рамке**
   - Задача: поздние архивы, башни, лаборатории.
   - Моделирование: круглая/шестигранная линза-диск, вокруг толстая рама, 2-3 держателя к стене. Линзу слегка наклонить к камере.
   - Материалы: `glass_bluegreen` или amethyst, рама медь/латунь. LOD1 - диск + рама.

53. **Янтарная производственная лампа**
   - Задача: индустриальные здания, работающие циклы.
   - Моделирование: маленький корпус box/cylinder, стеклянный amber-вкладыш, защитная металлическая скоба сверху. Размещать у станков/ворот.
   - Материалы: amber glass с emission 0.2-0.6, металл темный. Для `idle_no_workers` можно выключать emission.

54. **Световой маячок на башенке**
   - Задача: поздние civic/defense/market landmarks.
   - Моделирование: короткая стойка, стеклянный колпак шестигранником, маленькая крыша-колпачок. Диаметр 0.15-0.25 м для 1x1.
   - Материалы: glass pale cyan, металл/камень. Не заливать объект сильным bloom.

55. **Медная трубка энергии**
   - Задача: магико-технические поздние апгрейды.
   - Моделирование: curve/beam между механизмом и стеной, 8-12 сегментов, 2 крепежных кольца. Трубка должна иметь логичный маршрут и не висеть без опор.
   - Материалы: медь; маленькие glass вставки только в местах соединений.

56. **Кристальный предохранитель**
   - Задача: маленькая деталь на станках/дверях поздних зданий.
   - Моделирование: тонкий кристалл 6 граней внутри U-образной металлической скобы. Размер 0.08-0.14 м.
   - Материалы: amethyst/cyan, скоба iron/copper. LOD1 - один цветной prism.

57. **Рунная каменная печать**
   - Задача: руины, архивы, хранилища.
   - Моделирование: круглый или квадратный каменный диск на стене, сверху 2-4 простых рунных stroke как raised geometry. Не писать реальные слова.
   - Материалы: pale stone, руны чуть светлее или слабый amethyst.

58. **Латунный индикатор давления**
   - Задача: индустрия и механизмы.
   - Моделирование: круглый диск 12-16 сегментов, стрелка как тонкий box, два маленьких болта. Крепить на трубу/панель.
   - Материалы: латунь/copper, темная шкала без мелкого текста. LOD1 - диск и стрелка.

59. **Светящийся шов каменной плиты**
   - Задача: поздние магические ворота/руины.
   - Моделирование: тонкие полосы в стыках 2-3 каменных блоков, как отдельные emissive boxes глубиной 0.005-0.01. Не делать на каждой плите.
   - Материалы: restrained amethyst/cyan emission. LOD1 - одна светлая линия.

60. **Кристальная капля в подвесе**
   - Задача: декоративная магия на рынках/храмах/социальных зданиях.
   - Моделирование: маленький шестигранный кристалл, сверху колечко и короткий шнур. Кристалл должен висеть от балки, шнур касается балки.
   - Материалы: amethyst или glass cyan, rope/metal. LOD1 - кристалл без кольца.

## Дворовые props и бытовые детали

61. **Бочка с металлическими обручами**
   - Задача: универсальный двор, storage, industry.
   - Моделирование: цилиндр 12-16 сегментов с лёгким barrel profile через bevel/scale центральных вершин, 2-3 обруча торусами или тонкими цилиндрами.
   - Материалы: дерево, металл. Для LOD1 цилиндр 10 сегментов, обручи как цветовые полосы.

62. **Ящик с диагональной планкой**
   - Задача: readable prop для дворов.
   - Моделирование: box, 4 боковые планки, диагональ на видимой стороне. Добавить крышку с небольшим выступом.
   - Материалы: дерево 2 оттенка. Не делать микрогвозди, если ящик маленький.

63. **Мешок с завязкой**
   - Задача: ресурсы, поля, склады.
   - Моделирование: UV sphere или bevelled cube, слегка сплющенный, сверху маленькая шейка-цилиндр и веревочная завязка. Основание должно быть плоским.
   - Материалы: ткань/мешковина, rope. LOD1 - один мешок без завязки.

64. **Связка досок**
   - Задача: строительство, лесопилка, жилье.
   - Моделирование: 3-6 отдельных beams разной длины, лежат стопкой, поверх одна веревочная стяжка. Нижние доски касаются ground/floor.
   - Материалы: дерево, rope. Для damaged - разложить доски веером.

65. **Стопка каменных блоков**
   - Задача: construction и каменные апгрейды.
   - Моделирование: 3-5 beveled boxes, разный размер, слегка смещены. Не ставить блоки левитирующими.
   - Материалы: stone_block, темные швы. LOD1 - 2-3 блока.

66. **Моток веревки**
   - Задача: канатные, строительные, портовые и farm детали.
   - Моделирование: 2-3 torus с низкими сегментами или спираль из curve bevel_depth. Добавить маленькую бирку/узел.
   - Материалы: rope warm, darker inner shadow. Для массового runtime избегать torus > 24 сегментов.

67. **Инструментальная полка**
   - Задача: ремесленные здания.
   - Моделирование: задняя доска, горизонтальная полка, 2-4 простых silhouette tools: молоток, клещи, нож, крюк. Инструменты крупные, без микродеталей.
   - Материалы: дерево, iron. LOD1 - полка + 2 темных формы.

68. **Маленькая тележка**
   - Задача: дворовая логистика.
   - Моделирование: короб-тележка, 2 колеса цилиндрами 12 сегментов, две ручки-балки. Колеса касаются земли.
   - Материалы: дерево, iron для оси. Для damaged можно снять одно колесо и положить рядом.

69. **Корзина из лозы**
   - Задача: поля, рынки, дома.
   - Моделирование: усеченный цилиндр/конус 12 сегментов, сверху толстый обод, ручка дугой из curve. Плетение передавать 2-3 горизонтальными полосами.
   - Материалы: warm wicker. LOD1 - конус + ручка.

70. **Столик-верстак**
   - Задача: ремесленность и readable purpose.
   - Моделирование: tabletop box, 4 ножки, нижняя перекладина, 1-2 предмета сверху. Ножки должны касаться земли/пола.
   - Материалы: дерево, props по зданию. Не ставить на крышу без смысла.

## Озеленение, земля и окружение клетки

71. **Низкий пучок травы**
   - Задача: смягчить края ground-клетки.
   - Моделирование: 3-5 коротких листовых planes или тонких beams из одной точки, высота 0.08-0.16 м. Размещать группами по краям.
   - Материалы: 2 зеленых оттенка. LOD1 - 2 planes.

72. **Высокая трава у стены**
   - Задача: заросший восстановительный мир.
   - Моделирование: 5-8 листьев разной высоты 0.18-0.35 м, изгиб через поворот. Нижние точки в земле.
   - Материалы: deep green + light tips. Не закрывать двери.

73. **Клумба в каменном кольце**
   - Задача: civic/housing декор.
   - Моделирование: 6-10 камешков по овалу, внутри земляной плоский disk/box, 3-5 цветов. Камни касаются земли и слегка пересекаются.
   - Материалы: stone_light, soil, цветы red/yellow/lilac.

74. **Прямоугольная деревянная клумба**
   - Задача: дома и городские участки.
   - Моделирование: 4 доски борта, земля внутри ниже борта, 4-7 растений. Углы бортов должны пересекаться без щелей.
   - Материалы: wood, earth, flower colors.

75. **Цветок-колокольчик**
   - Задача: сказочный, но не магический акцент.
   - Моделирование: стебель цилиндром 6 вершин, цветок как маленький конус/колокольчик 6-8 вершин, 1-2 листа.
   - Материалы: lilac/blue/yellow, green stem. LOD1 - цветная точка + стебель.

76. **Камешки у фундамента**
   - Задача: соединить здание с землей.
   - Моделирование: 4-8 low frustum/ico shapes, разные размеры, вокруг цоколя. Не выше 0.08 м для мелких.
   - Материалы: warm stone, отдельные темные камни. LOD1 - 3 камня.

77. **Моховая полоса**
   - Задача: каменные фундаменты, руины, влажные края.
   - Моделирование: тонкая неровная плоскость/strip вдоль основания, несколько маленьких blobs. Не использовать как объемную подставку.
   - Материалы: moss green, darker edge.

78. **Малый куст ветролиста**
   - Задача: связать мир с ресурсом ветролиста.
   - Моделирование: 5-9 крупных листьев из простых 6-вершинных shapes, центральная точка у земли, листья толстые и читаемые.
   - Материалы: насыщенный зеленый, светлая жилка. Не ставить на каждый объект.

79. **Дорожка из светлой земли**
   - Задача: направление входа.
   - Моделирование: плоская неровная strip mesh на уровне ground, 6-10 вершин, без высоты или с 0.005 м. Подходит к двери.
   - Материалы: earth_light, мягкие края. LOD не нужен как отдельная геометрия при sprite render.

80. **Дорожка из каменных плит**
   - Задача: более развитые здания.
   - Моделирование: 3-6 плоских плит, разные формы, bevel 0.01-0.02. Плиты не должны поднимать весь ground.
   - Материалы: stone_light, moss/earth между плитами.

## Хранилища, защита и статус здания

81. **Деревянный шип на крыше**
   - Задача: storage/defense силуэт.
   - Моделирование: конус 6-8 сегментов или заостренная балка, основание-крепеж. Наклонить немного наружу.
   - Материалы: wood_dark, для late - metal/gold tips. Не делать слишком агрессивно на мирных домах.

82. **Металлический зубец стены**
   - Задача: укрепленные склады и башни.
   - Моделирование: короткий клин из 5-6 вершин, ряд из 3-5 зубцов с общим основанием. Каждый зубец касается основания.
   - Материалы: iron, edge highlight.

83. **Золотая угловая накладка**
   - Задача: богатые хранилища и поздние prestige buildings.
   - Моделирование: L-образная тонкая накладка на углу крыши/стены, 2-3 болта. Цвет золота использовать как акцент, не заливать большую площадь.
   - Материалы: muted gold, темные швы.

84. **Пломба хранилища**
   - Задача: показать закрытость/ценность.
   - Моделирование: круглый диск на двери или ящике, через него проходит веревка/лента. На диске простой знак без текста.
   - Материалы: wax red/amber или metal seal.

85. **Цепная перемычка**
   - Задача: индустриальные, складские, damaged детали.
   - Моделирование: 3-6 звеньев, каждое как torus низкой детализации или два curved cylinders. Для дальних LOD заменить одной темной curve.
   - Материалы: iron_dark. Не использовать в больших количествах на малых моделях.

86. **Крепежный канат на грузе**
   - Задача: связать ящики/бревна/камни в правдоподобный prop.
   - Моделирование: 2 perpendicular ropes вокруг группы объектов, узел сбоку. Веревки слегка пересекают груз, чтобы не висели.
   - Материалы: rope.

87. **Защитная решетка окна**
   - Задача: склады, тюрьмы, башни.
   - Моделирование: 2-3 вертикальных и 1-2 горизонтальных прута внутри оконной ниши. Пруты не заменяют стекло, если окно должно быть стеклянным.
   - Материалы: iron. LOD1 - крест.

88. **Угловой сигнальный шест**
   - Задача: обозначить важное здание.
   - Моделирование: высокий тонкий шест с маленьким навершием и лентой/фонариком. Основание закрепить в камне/дереве.
   - Материалы: wood/metal, cloth/amber. Следить, чтобы не закрывал соседние тайлы.

89. **Ремонтная заплата на стене**
   - Задача: readable damaged/repaired state.
   - Моделирование: 2-4 доски или металлическая пластина поверх трещины. Доски разной длины, гвозди крупные.
   - Материалы: контраст к основной стене. Использовать только там, где логично.

90. **Разбитый, но опирающийся фрагмент**
   - Задача: damaged/ruined без левитации.
   - Моделирование: кусок балки/камня положить на землю или прислонить к стене. Если фрагмент висит на стене, добавить оставшуюся опору/петлю.
   - Материалы: как исходная конструкция, darker damage edge.

## Производственные и ремесленные декоративные детали

91. **Малый зубчатый механизм**
   - Задача: поздние workshop/industry апгрейды.
   - Моделирование: цилиндр-диск 12-16 сегментов, зубья как 8-12 маленьких boxes по окружности или упрощенная звезда. Не делать слишком мелко.
   - Материалы: metal_worn/copper. LOD1 - зубчатый диск без отдельных зубьев.

92. **Ручной ворот**
   - Задача: шахты, карьеры, канатный двор, склады.
   - Моделирование: горизонтальный цилиндр-барабан на двух стойках, ручка сбоку, веревка намотана 1-2 витками.
   - Материалы: wood/iron/rope. Стойки касаются земли или платформы.

93. **Сортировочный лоток**
   - Задача: поля, семена, лен, руда, песок.
   - Моделирование: shallow tray: дно, 4 низких борта, внутри 3-5 маленьких piles. Наклонить слегка к камере.
   - Материалы: wood, resource color. LOD1 - tray + один pile.

94. **Подвесной крюк**
   - Задача: краны, мастерские, склады.
   - Моделирование: вертикальный трос/цепь, крюк как изогнутая форма из 2-3 cylinders или плоский hook mesh. Крюк должен висеть от балки.
   - Материалы: iron, rope/chain. Не оставлять без верхней точки крепления.

95. **Тканевый ремень привода**
   - Задача: механизация без sci-fi.
   - Моделирование: две окружности/барабана и ремень как две параллельные straight beams/curves. Ремень должен касаться барабанов.
   - Материалы: cloth_dark/leather, metal/wood drums.

96. **Пучок сырья у входа**
   - Задача: показать input resource.
   - Моделирование: набор 3-6 bundles: лен, ветролист, бревна, руда или ткань. Делать разными silhouettes, а не одинаковыми кубами.
   - Материалы: по ресурсу; добавить 1 rope tie.

97. **Готовая продукция на стойке**
   - Задача: state `ready`.
   - Моделирование: маленькая стойка/полка и 2-4 readable output props: мотки веревки, доски, кирпичи, стеклянные слитки. В ready state объем больше, чем в active.
   - Материалы: output resource colors, tags optional.

98. **Пыльная рабочая метла**
   - Задача: бытовая деталь мастерских и дворов.
   - Моделирование: тонкая ручка, пучок щетины как 5-7 коротких beams/planes. Прислонить к стене под углом, нижний край касается земли.
   - Материалы: wood + straw. LOD1 - ручка и один wedge.

99. **Малый ящик инструментов**
   - Задача: construction/industry detail.
   - Моделирование: box с открытой крышкой или закрытый beveled box, ручка-дуга, 1-2 инструмента сверху. Размер 0.25-0.45 м.
   - Материалы: wood/metal, tools iron. В construction ставить рядом с материалами.

100. **Калибровочная стойка качества**
   - Задача: поздние здания с шансом качественного результата.
   - Моделирование: две вертикальные стойки, верхняя планка, маленький аккуратный образец продукции и цветная бирка. Для rope yard - светлая бухта; для glass - чистая пластина; для lumber - полированная доска.
   - Материалы: premium wood/copper, output material, small blue/amber tag. LOD1 - стойка и один образец.

## Рекомендации по внедрению в component library

1. Начать с универсальных helpers: `add_flag_ribbon`, `add_rope_tie`, `add_bolt`, `add_small_lantern`, `add_crate`, `add_barrel`, `add_resource_bundle`.
2. Затем добавить фасадные детали: `add_deep_window_frame`, `add_shutters`, `add_door_hardware`, `add_wall_patch`, `add_stone_arch`.
3. После этого выделить эолийские мотивы: `add_wind_vane_leaf`, `add_mini_windwheel`, `add_wind_spiral_sign`, `add_crystal_mount`, `add_sail_canopy`.
4. Для каждого helper предусмотреть параметры `scale`, `rotation`, `material_variant`, `damaged=False`, `lod_level=0`.
5. Для массовых building assets держать декоративный бюджет: раннее 1x1 здание - 5-10 декоративных элементов, развитое 1x1 - 10-18, 2x2 - 18-30. Повторяемые болты/камешки считать группами, а не отдельной художественной идеей.
