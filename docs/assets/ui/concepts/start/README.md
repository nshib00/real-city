# Стартовая страница: макеты 1Б.2

Макеты реализованы в React на настоящих русских текстах и сохранены как снимки Chromium. Направление: локальная изометрическая диорама поселения и компактная форма рядом; один экран первого решения. Шрифт Trebuchet MS / Segoe UI сохранён. Цвета: пергамент `#f2e6c8`, бумага `#fff8e8`, чернила `#20302b`, хвоя `#286447`, сланец `#526052`, латунь `#c89b51`.

- `desktop-login.png`, `desktop-register.png`: 1440×900; сцена занимает около 60% доступной ширины, форма около 40%.
- `mobile-login.png`, `mobile-register.png`: 390×844; компактная сцена сверху, главное действие и форма в доступной области. Кнопка регистрации заканчивается на y=749; горизонтальное переполнение отсутствует.
- `small-register.png`: 320×700; форма прокручивается внутри экрана.
- `short-register.png`: 390×480, модель уменьшившейся области просмотра; сцена скрыта, форма прокручивается. Это проверка компоновки, а не испытание настоящей экранной клавиатуры.
- `desktop-first-map.png`, `mobile-first-map.png`: помощь первого входа над настоящим Pixi canvas, изолированный API; отдельная полоса инструментов и навигация доступны, помощь можно закрыть сразу.

Три принципа: строительство рядом с игроками; добыча и производство; защита построек и путей к запасам. Счётчиков онлайн нет. Статус доступности получается из JSON `/ready`, недоступность проверки не блокирует вход. Опубликованной страницы правил в проекте нет: ссылка на несуществующий документ не добавлена.

Сцена создана заново из собственной векторной геометрии. Исходник, адаптивный экспорт и бюджет: `frontend/public/assets/ui/start/README.md`. Отдельный WebGL до входа не запускается. Полная интеграционная приёмка с настоящим сервером и клавиатурой — 1Б.7.
