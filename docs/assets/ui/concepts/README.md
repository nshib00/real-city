# Концепты фазы 1

`moodboard.svg` — собственные ассеты и назначение материалов. `edge-1440.svg` и `desk-1440.svg` — два desktop-варианта; `edge-1024.svg` и `mobile-390.svg` — адаптивная композиция. PNG встроены внутрь SVG. Это проектные схемы, не снимки работающего интерфейса.

Пересборка: `python3 tools/assets/ui/build_concepts.py` из корня проекта. Числа схем фиксируют срез каталога 30.10.2026; после изменения стоимости обновить генератор и сравнить с импортируемым React-каталогом. [Расчёт площади](geometry.md), [решения и ограничения ревью](../../../art/aeolian-ui-style-guide.md).

Кликабельный вариант: `frontend/design.html`, инструкции в style guide. Реальные браузерные снимки ожидают доступного Vite/Chromium и не заменяются этими файлами.
