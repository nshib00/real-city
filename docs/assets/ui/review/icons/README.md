# Проверка иконок

`pilot.png` — просмотренные 12 пилотных знаков. `resources.png` — просмотренный полный каталог миниатюр. `index.html` — все знаки на светлом, тёмном и обесцвеченном фоне в размерах 16/20/32/64 px. Отдельные PNG/WebP — проверенные экспорты 64×64 с прозрачностью. Генератор: `tools/assets/ui/export_icon_review.py`.

Это изображения ассетов, не скриншоты игрового интерфейса. Обесцвечивание не заменяет симуляцию протанопии/дейтеранопии/тританопии.

Браузерный путь восстановлен 31.10.2026. [Результаты, снимки и ограничения](../../../../frontend/interface-browser-review.md). Выполнены:

- [x] Снимки HUD, каталога, инспектора и уведомлений над проектными ассетами мира.
- [x] DPR 1/2, масштаб листа 100/200%, размеры окон фазы 5 и крупный текст.
- [x] Малый монохромный ResourceIcon, fallback без изменения размеров; конфликт CSS исправлен.
- [x] Оба орнамента в одном каркасе панели.
- [x] Экспертное ревью пилота без подписей, с подписями и в игровом интерфейсе.
- [ ] Полная матрица сочетаний владения, редкости и угроз на одном объекте (7А.5).
- [x] Три цветовые симуляции и ограниченный аудит computed colors/alpha на худшем фоне.

Снимки DPR 1/2, масштабы, fallback и цветовые симуляции получены настоящим Chromium. Пилот без подписей и с ними прошёл экспертное визуальное ревью; это не пользовательское исследование. Полные комбинации владения/редкости/угроз и отдельная оптическая геометрия каждого знака 16 px остаются в 7А.5 и 7А.2. Проверки всех ролей и комбинаций экранов в 7А.9 не объявляются завершёнными по одному листу ассетов.
