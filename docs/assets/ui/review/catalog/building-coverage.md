Подробная матрица уровней/состояний, дубли ID, footprint и дословно объявленное происхождение — в `building-coverage.json`. Отсутствие уровневого PNG у модульной дороги не доказывает отсутствие runtime-отображения. Заимствование визуала другого уровня/состояния не считается отдельным финальным ассетом.

Контактный лист: `building-contact-sheet.html`, требует локального HTTP-сервера из корня репозитория. Это входные материалы для ревью, не принятые скриншоты игры. Пустое declared_provenance означает отсутствие сведений в manifest; наличие source/license ещё не подтверждает права.
