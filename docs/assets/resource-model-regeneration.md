# Перегенерация игровых ресурсов

Этот документ описывает прежнюю партию ресурсных моделей. Девять GLB и PNG новой категории `weapons` созданы отдельной партией по [спецификации вооружения](weapon-resource-models.md).

## Задание

Полный Blender-набор из 34 ресурсов `shared/catalog/resources.ts`, включая
население, валюты, сырье, промышленные материалы, топливо и редкие ресурсы.
Дополнительно подготовлены PNG-иконки для ресурсов из `docs/game-design/resources-list.md`,
которые еще не добавлены в игровой каталог или были добавлены без ассета.
Названия, id и игровые стоимости не меняются.

## Визуальная спецификация

- Яркие изометрические предметы Эолии, прозрачный фон, без земли и декоративных подложек.
- PNG 256x256, единые ракурс и дневной свет; предмет занимает около 82% кадра.
- GLB каждого ресурса и общий редактируемый Blender-исходник с 34 коллекциями.
- Pivot по центру основания, примененные transforms, замкнутые поверхности.
- Бюджет иконок: до 6000 треугольников для составных крупных планов; это UI-модели,
  не массовые ресурсные узлы карты. Отдельные LOD и анимации не используются.
- Стекло отличается от кристалла листовым силуэтом, сталь от железных слитков
  профилями, металл стопкой лома, песок насыпью, нефть темной бочкой.
- Ветролист имеет широкие плотные зеленые листья; супер-волокно представляет собой
  связку волокон, а не перекрашенный ветролист. Кристаллы тонкие, шестигранные,
  аметистовые, с острыми вершинами.
- Референсные принципы: крупные узнаваемые формы, насыщенные материальные цвета,
  читаемость при уменьшении до 24-48 px. Старый набор используется для визуальной
  преемственности, без копирования сторонних игровых ассетов.

## Пайплайн

`tools/assets/blender/regenerate_resource_models.py` пересобирает геометрию,
экспортирует GLB, рендерит PNG и проверяет обратный импорт всех моделей.
Тяжелая генерация запускается через MCP в отдельном фоновом Blender,
не затрагивая открытую пользовательскую сцену.

`tools/assets/generate_resource_icon_pngs.py` - fallback-пайплайн без Blender.
Он обновляет PNG для новых/документированных ресурсов, дополняет
`manifest.json` PNG-only записями и перерисовывает эолийский кристалл с более
стеклянными аметистовыми гранями.

Выход: `frontend/public/assets/resources/icons/`. Иконки автоматически используются
существующим `ResourceIcon`; пути сохраняются. `manifest.json` содержит id,
имена, категории, файлы, количество треугольников и параметры кадрирования.

## Результат проверки

Сейчас в runtime-папке 74 PNG 256x256, 34 GLB и общий `.blend` с 34
Blender-коллекциями. Каталог покрыт полностью, а `manifest.json` может быть
супермножеством каталога, потому что включает подготовленные ресурсы из
документации. Максимум на GLB-модель: 3216 треугольников.
Все существующие GLB прошли обратный импорт, проверку замкнутости, ориентации
граней и transforms. PNG имеют прозрачные поля, не обрезаны и проверены на
листах размеров 24/32/48 px.

Проверка: `python3 tools/assets/validate_resource_models.py`.
Отчеты: `validation-report.json`, `roundtrip-validation.json`,
`docs-fallback-validation.json`.
Обзор: `resource_icons_contact_sheet.png`, `resource_icons_small_review.png`,
`resource_icons_docs_fallback_review.png`,
`resource_icons_docs_fallback_small_review.png`.
