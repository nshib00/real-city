# Декор каменного дома: 20 новых компонентов

Компоненты находятся в `tools/assets/blender/real_city/components/stone_house_decor.py` и зарегистрированы в `registry.py`. Это отдельные детали для будущих вариантов каменного дома; они не меняют баланс, существующие модели и наборы состояний.

## Правила размещения

- Все фабрики принимают `(name, collection, mats, loc)`. `name` должен быть уникальным внутри сцены. Дополнительные параметры заданы явно в сигнатурах.
- Фасад направлен к `-Y`. Для настенных деталей `loc` — центр крепления к поверхности; для кровельных — точка опоры на кровле или трубе; для дворовых — точка контакта с землёй.
- Камень остаётся главным материалом. Медь и тёплый свет служат малыми акцентами. Кровельные элементы используют зелёную палитру крыши.
- Декор ставить только на подходящую опору: например, корону — на готовую трубу, накладку — на конёк, водосборную цепь — под карниз. Перед экспортом проверить пересечения, отсутствие висящих деталей и читаемость входа в изометрии.
- В `construction` размещать только уже построенные детали; в `damaged` убирать или физически повреждать декор вместе с соответствующей частью дома.

| --- | --- | --- |

| `add_masonry_ribbon` | Пояс из пяти чередующихся блоков поверх тёмного шва | Между проёмами или этажами |
| `add_copper_wall_rosette` | Медная четырёхлепестковая розетка на каменной основе | На свободном участке фасада |
| `add_window_drain_lip` | Каменный подоконник с медным капельником | Под окном |
| `add_arched_vent` | Каменная полукруглая вентиляция с тремя прутьями | У цоколя или под фронтоном |
| `add_corner_stone_bracket` | Трёхъярусный каменный угловой кронштейн с крышкой | На углу стены |
| `add_wall_lantern_niche` | Светлая лампа внутри каменной ниши с козырьком | Рядом со входом |

| Функция | Элемент | Размещение |
| --- | --- | --- |
| `add_paved_stone_sun` | Круглая вставка из восьми лучевых плит | В центре дорожки или площадки |

Для первого визуального варианта выбирать 2–4 элемента. На поздних вариантах число элементов может расти, но вход, зелёная крыша и кладка остаются главными читаемыми признаками дома.
