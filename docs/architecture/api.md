# API Real City

## Версионирование

Публичный HTTP API живёт под префиксом `/api/v1`. Несовместимые изменения требуют нового префикса версии. Внутри одной версии допускаются только совместимые расширения: новые поля ответа, новые необязательные поля запроса, новые значения enum только после обновления клиентов.

## Ошибки

Все ошибки возвращаются в единой форме:

```json
{
  "error": {
    "kind": "validation",
    "message": "invalid request",
    "fields": {
      "name": "must be present"
    }
  }
}
```

`kind` стабилен для клиентской логики. `message` предназначен для диагностики и может уточняться. `fields` используется для ошибок валидации и конфликтов ресурсов.

## Пагинация

Для MVP списки используют `limit` с серверным максимумом `200`. Новые большие списки должны переходить на cursor pagination: `cursor`, `limit`, `next_cursor`. Cursor считается opaque-строкой, клиент не должен разбирать его содержимое.

## Idempotency

Небезопасные POST, создающие долговременное игровое состояние, требуют `Idempotency-Key` длиной 8–128 символов: размещение здания, применение оружия к зданию или монстру, создание монстра для атаки, рыночный ордер, приглашение и расходование казны союза. Ключ ограничен игроком, HTTP-методом и маршрутом; отпечаток запроса учитывает query, `Content-Type` и тело. Повтор успешного запроса возвращает сохранённые статус, заголовки и тело с `Idempotency-Replayed: true`; тот же ключ с другим запросом получает `409 Conflict`. PostgreSQL хранит резервацию и ответ между экземплярами и рестартами; без PostgreSQL доступно только локальное хранилище процесса.

## Совместимость клиентов

Frontend API-клиент находится в `frontend/src/shared/api`. Для ручных клиентов обязательны contract tests на путь, метод и критичные заголовки. OpenAPI-описание формируется из `backend/internal/adapter/http/openapi.go` командой `cd backend && go run ./cmd/openapi-gen`; структурная freshness-проверка сравнивает весь снимок с runtime-контрактом и проверяет его API-маршруты. Снимок хранится в `backend/docs/swagger/openapi.json`, runtime-версия доступна по `/swagger/openapi.json`.

## Депрекация

Поле или endpoint нельзя удалять без переходного периода. Сначала добавляется новое поле/endpoint, затем старое помечается как deprecated в OpenAPI и документации, после чего удаление возможно только в новой версии API.
