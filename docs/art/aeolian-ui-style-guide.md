## Компоновки на игровом содержимом

Схемы — самостоятельные SVG, **не браузерные скриншоты**. Изображения встроены, поэтому файлы можно открыть отдельно. Данные цикла: Землянка, 1×1, 50 монет и 3 древесины, 10 с, +1 житель, прочность 35; источник `shared/catalog/buildings.ts`. Прототип импортирует каталог; схемы фиксируют этот срез.

| Вариант | Схема | Карта вне прямоугольников HUD | Чтение и решение |
|---|---|---|---|
| А: инструменты по краям, 1440×900 | [Desktop А](../assets/ui/concepts/edge-1440.svg) | 71.0% | Цель → цена → состояние в одном правом столбце; верхняя строка служит сверкой запасов |
| Б: нижний рабочий стол, 1440×900 | [Desktop Б](../assets/ui/concepts/desk-1440.svg) | 77.9% | Карта открыта сверху, но цель в центре и действие внизу разделены; длинный инспектор требует прокрутки |
| А: 1024×768 | [Компактный desktop](../assets/ui/concepts/edge-1024.svg) | 63.0% | Сохраняет порядок информации; полезная ширина карты падает, нужен сворачиваемый инспектор |
| Мобильный лист, 390×844 | [Mobile](../assets/ui/concepts/mobile-390.svg) | 54.1% | Ресурсы сверху, действия над журналом, цель/цена в закрываемом листе; карту можно раскрыть закрытием листа |

Расчёт: площадь сцены минус непересекающиеся прямоугольники HUD, без оценки восприятия, рамки и читаемости отдельных тайлов. [Числа и ограничения](../assets/ui/concepts/geometry.md). Геометрия статических схем отличается от адаптивной CSS-сцены; эти проценты нельзя выдавать за DOM-измерения.

Предварительно выбран **А + мобильный лист**: цена, причина блокировки и подтверждение стоят в одном месте, а журнал не становится вторым рабочим столом. Б оставлен переключаемым для сравнения. Сравнение скорости сейчас эвристическое: А требует перевода взгляда карта → правый инспектор, Б — карта → нижний инспектор, оба требуют одинаковые пять действий после выбора тайла до открытия объекта. Замера времени чтения с участниками не было. Б отклонён как основной из-за вероятной конкуренции нижнего стола с журналом и touch-инструментами; это гипотеза для браузерного ревью.

Слева выравниваются заголовки, подписи, числа цены и кнопки. Центрирование применяется к изображению здания и самому тайлу. Мобильный лист имеет собственную прокрутку; кнопка «Закрыть» возвращает к выделенному тайлу. В перспективе игровая камера должна удерживать выбранный объект вне листа; макет этого не реализует.

## Цвет и форма — независимые каналы

Направление: дерево `#20332F`, рабочая поверхность `#FFF8E8`, камень `#F2E6C8`, действие `#286447`, латунь `#C89B51`, технология `#684A91`. Полная палитра, её внедрение и инструментальная проверка контраста остаются фазой 1А. Эти цвета локальны для макета; игровые токены не заменены.

|---|---|---|
| Свой | Спокойный зелёный | Круг с точкой `◉`, «Ваш объект» |
| Союзный | Информационный синий | Два связанных кольца, «Союз: имя» |
| Чужой | Нейтральный тёмный | Ромб, имя владельца; сам по себе не означает врага |
| Нейтральный | Серый | Пустой контур, «Нейтральный объект» |
| Выбранный | Контрастный двойной контур | Угловые метки/вдавленный тайл, состояние `aria-pressed`; независимо от владельца |
| Угроза | Красный | Треугольник с `!`, причина и цель угрозы |
| Защита | Информационный синий | Щит и «Под защитой до…»; не маскирует владельца |
| Стройка | Янтарный | Часы, прерывистый контур и «Строится: осталось…» |
| Урон | Красный | Надломленный контур, «Прочность: X / Y», действие ремонта |
| Доступно | Зелёный | Обычная кнопка с глаголом и ценой, галочка только у результата проверки |
| Недоступно | Нейтральная поверхность | Пунктир и конкретная причина рядом с кнопкой; `disabled` в DOM |
| Нет связи | Предупреждающий янтарный | Разрыв соединения и «Нет связи», повтор только там, где применим |
| Редкость | Отдельная категория данных | Подпись «Обычный/редкий/…» и число насечек; не выводить редкость из фиолетового цвета |

Композиция слоёв: основание объекта → знак владельца → выбранный контур → состояние/угроза с отдельной подписью. Например, «◉ Ваш объект; ◷ Строится; ⚠ Угроза» сохраняет все смыслы одновременно. В градациях серого нужно прочесть подписи и отличить круг, ромб, щит и треугольник; инструментальное/браузерное подтверждение ещё не выполнено. В макете реализованы свой объект, выбор, стройка, блокировки ресурсов и сети. Остальная матрица задаёт контракт последующих фаз и не выдаётся за уже работающий HUD.

## Интерактивный цикл

Запуск: из `frontend` выполнить `npm run dev -- --host 127.0.0.1 --strictPort`, открыть `http://127.0.0.1:5173/design.html`. Исходник `frontend/src/stories/AeolianPrototype.tsx`, локальные стили `aeolian-prototype.css`. Производственный `App` не подключает макет.

1. Выбрать свободный тайл (ратуша занимает один тайл, он недоступен).
2. Открыть строительство и прочесть данные Землянки из действующего каталога.
3. Проверить цену; переключатели нехватки и отсутствия связи показывают причину и блокируют действие.
4. Открыть предпросмотр: выделенный контур указывает место, «Назад к тайлу» отменяет выбор постройки.
5. Нажать «Разместить в макете»: появляется спрайт стройки и сообщение о принятии заявки в макете.
6. Открыть объект из инспектора или повторным нажатием на стройку. Таймер остановлен на 0/10, прогресс не подделывается.

Кнопки доступны с клавиатуры; Escape/«Закрыть» убирают инспектор и возвращают фокус к выбранному тайлу. Открытие переносит фокус на заголовок; панели не модальные, фокус не заперт. Touch-цели минимум 44 px; hover не нужен. После размещения остальные тайлы временно недоступны: это один цикл макета, не полноценная навигация мира. Сброс очищает цикл и диагностические переключатели. Баланс 5000 — фиксированная fixture, списания и запросов API нет. Перед переносом в игру потребуются серверная валидация, действительные запасы, ошибки размещения и поток обновлений.

Шрифт **не изменён**: обе переменные остаются `"Trebuchet MS", "Segoe UI", ui-sans-serif, system-ui, sans-serif`. Макет наследует `--font-ui`; новые гарнитуры и сетевые загрузки отсутствуют. Размеры 12–24 px, обычный текст 16 px; гарнитура на машине зависит от установленных fallback, поэтому проверка только имён CSS не заменяет визуальный просмотр кириллицы.

## Состояния и доступная обратная связь — фаза 6

Контракт `ActionState`: ready — готово; blocked — недоступно с причиной; pending — ожидается сервер; success — получено подтверждение; error — действие не выполнено; cancelled — отменён запрос, результат на сервере нужно проверить; cooldown — восстановление; offline — подтверждение недоступно. У таймеров отключать live-объявления, не объявлять секунды. `APIError.kind` переводится в понятную причину без вывода приватного payload. Состояния всегда подписаны; ошибка имеет двойной, offline/cooldown — пунктирный маркер. Подробные правила и ограничения: [отчёт фазы 6](../frontend/interface-phase-6.md).

Нажатие/выделение показываются сразу, списание ресурсов и успешный результат — после ответа сервера. Не путать принятие запроса строительства с завершением постройки. Сбой соединения и прерывание запроса не доказывают отмену серверного действия. Новые собственные угрозы объявлять отдельным polite/status, историю и realtime-тики — не объявлять.

CSS-эффекты отключаются системным reduced motion или кнопкой «Эффекты». Шрифт остаётся прежним. Для классической темы используются непрозрачный фон `#293e38`, текст `#f9f4df` (10.34:1), границы `#c0ccb9` (6.83:1). Её текстовый danger — `#ff9393`; CSS-эффекты, computed colors/alpha и три цветовые симуляции проверены в браузере; границы покрытия и оставшаяся интеграция анимаций мира указаны в отчёте приёмки.

## Итоговые правила внедрения — фаза 10

### Токены и типографика

Основные значения задаются в `frontend/src/app/styles/tokens.css`; слой Эолии — в `aeolian.css`, состояния элементов — в `control-states.css`. Палитра поверхности не меняет семантику карты. Сохранять `--font-ui` и `--font-display` с текущим Trebuchet/Segoe/system fallback; новые загрузки шрифтов запрещены. При любом изменении проверять обычный/приглушённый/ошибочный текст, фокус, disabled и выбранное состояние на поверхности карты.

### Компоненты и состояния

Использовать общие `Button`, `IconButton`, `Tabs`, `Drawer`, `Modal`, `ActionState`, `StatusState`, `ObjectMarks` и `ResourceIcon`. У действия должны быть видимые состояния готовности, ожидания сервера, успеха, ошибки, блокировки, cooldown и offline. Причину блокировки писать рядом с действием; цвет не является единственным носителем смысла. Модальные окна возвращают фокус инициатору, Escape закрывает допустимую панель, reduced motion отключает декоративное движение.

### Ассеты и декор

Функциональные знаки брать из `frontend/public/assets/ui/icons/manifest.json`, предметные миниатюры ресурсов — из исторического `assets/resources/icons/`, орнамент — из `assets/ui/ornaments/`. Не подменять игровые 3D-модели UI-иконками и не вставлять текстуру под областью мелкого текста. Неизвестный/не загруженный файл должен иметь читаемый fallback без сдвига разметки. Перед добавлением экспорт проверить командами `npm run assets:ui` и `npm run assets:budget` из `frontend/`; сохранять исходник, имя, размер и происхождение в соответствующем реестре.

Уместно: один латунный крепёж на активной панели, подпись угрозы вместе с её знаком, предметная миниатюра в каталоге. Неуместно: повторять орнамент на каждой строке, обозначать редкость только аметистовым цветом, перекрывать карту непрозрачной декоративной рамкой, использовать glow как замену прогрессу или статусу. Основной рабочий путь и rollout/откат описаны в [инструкции выпуска](../operations/ui-rollout.md); набор компонентов и проверок — в [обзоре фронтенда](../frontend/README.md).
