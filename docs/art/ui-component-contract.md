# Контракт компонентов Эолии

Фаза 2, 30.10.2026. `tokens.css` сохраняет текущие цвета; новая палитра проверяется отдельно в фазе 1А. Общие стили вынесены в `components.css`, миграция экранов продолжается в фазах 3–4.

## Текст и токены

`--font-ui` и `--font-display` сохранены буквально: `"Trebuchet MS", "Segoe UI", ui-sans-serif, system-ui, sans-serif`. Новых загрузок шрифтов нет. Проверочная кириллица на стенде: «Стоимость строительства, прочность землянки». Наличие первой гарнитуры зависит от машины; реальный fallback ещё требует браузерного ревью.

Размеры: 0.75 / 0.875 / 1 / 1.125 rem. Интерлиньяж текста 1.5, заголовков 1.25. Числа ресурсов — tabular-nums lining-nums при поддержке гарнитурой. Отступы: 4 / 8 / 12 / 16 / 24 px. Минимальная цель общего управления — 44 px. Слои: HUD 10, диалог 30, tooltip 40. Отклик 120 мс, панель 160 мс; reduced motion обнуляет длительности.

## Поведение компонентов

- Button: primary/secondary/danger; loading блокирует повторное действие и задаёт aria-busy. Ответом сервера управляет потребитель.
- IconButton: обязательный label, текущий Lucide до миграции 7А, loading сохраняет имя. Hover — обводка, pressed — внутренний контур, disabled — пунктир, focus — видимая рамка. Причина блокировки должна быть рядом текстом.
- Tabs: один tab-stop, стрелки по кругу, Home/End; уникальные связи ARIA с панелью. Автоматическая активация для локального содержимого. SegmentedControl сохраняет кнопки с aria-pressed.
- Modal: удержание Tab, Escape закрывает верхнее окно, возврат фокуса. Drawer немодальный: закрытое содержимое inert; Escape внутри возвращает фокус, карта доступна.
- Tooltip: один фокусируемый ребёнок, aria-describedby, focus/hover, Escape. Курсор можно перевести на подсказку. Критичную инструкцию не оставлять только в tooltip.
- StatusState: empty/loading/offline/error, aria-busy при загрузке, alert для ошибки. Не объявлять каждый realtime-тик.

| Семейство | Представление | Подпись и fallback |

| Ресурс | Текущая 3D-миниатюра, стандартный слот 30 px | ResourceIcon требует label, по умолчанию role=img. Ошибка изображения заменяется Package того же размера с сохранением имени. decorative скрывает дубль рядом с текстом |

Фиксированный угловой CSS-фон без растяжения и перехвата ввода. `weave.svg`: оригинальная тканевая сетка 16×16 низкой непрозрачности для стенда. Созданы кодом в проекте, внешних материалов, ссылок и шрифтов нет; разрешено использовать и изменять в проекте. Исходник совпадает с экспортом. Вместе меньше 1 KiB. Масштабирование векторное, но чёткость DPR 1/2 ещё не принята визуально.

## Стенд и приёмка

`design.html`: одинаковые компоненты над схематическими светлой поляной и тёмным лесом. Землянка, цена и характеристики взяты из buildingCatalog. Есть default/active/disabled/loading, вкладки, tooltip, диалог, панель и отсутствующая миниатюра. Hover/focus/pressed проверяются взаимодействием.

Vitest: блокировка повторного действия, ARIA и стрелки вкладок, возврат фокуса, Escape, tooltip, fallback. Общий прогон: **328 тестов в 79 файлах прошли**; lint и production build прошли. Vite повторно завершился `listen EPERM 127.0.0.1:5173`. Поэтому визуальные проверки DPR, кириллицы, состояний и окружения карты остаются открыты в 2.3/2.4/2.6. Стенд не является доказательством проверки поверх реального Pixi-кадра.
