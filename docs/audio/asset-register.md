# Реестр происхождения звуков

Каждый исходник регистрируется до включения в каталог. Случайные сэмплы из сети без подтверждённой лицензии и права переработки использовать нельзя. Рецепт собственного синтеза считается исходником; запись Foley требует автора записи и даты. Master WAV и итоговый MP3 должны ссылаться на одну запись.

Для нового звука заполнить все поля; для собственного синтеза в колонке стороннего материала указать «нет». Для внешнего материала сохранить ссылку на условия лицензии и копию/версию условий на дату получения. Если лицензия не разрешает переработку и распространение в игре, не включать файл в сборку. Путь рецепта должен вести в `tools/audio/recipes/`; его параметры и seed обязаны позволять воспроизвести WAV. Для записи указывать исходный необработанный файл и шаги очистки. Варианты одного `sound_id` перечислять в отдельной строке или явно указывать их пути в одной строке.
