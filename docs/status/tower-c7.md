# Очередь C/7: сторожевая башня

Статус: **частично выполнено**.

Каталог содержит уровни 1–6 с ценами, временем, строителями и HP из плана; серверный путь `BuildingService.UpgradeTo` принимает следующий уровень по `upgradeLevels`. Для всех уровней заданы XP. Клиент выбирает соответствующие модели и спрайты; при выборе башни показывает голубую границу проектной геометрической зоны дозора (6, 8, 10, 12, 14 или 16 клеток).

Оповещения о монстрах пока не работают. Сервер не проверяет угрозы для башни, не ведёт дозорного, не создаёт и не передаёт события тревоги. Геометрическая граница на карте не является индикатором действующего обнаружения. Для завершения пункта нужен отдельный серверный расчёт и интеграция в симуляцию монстров. Файл `backend/internal/worker/simulation/monster_ai.go` уже имеет внешние незакоммиченные изменения и в этой работе не изменялся.
