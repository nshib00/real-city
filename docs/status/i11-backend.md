# Пункт 11: размер построек 1×1

Сервер принимает размещение, улучшение и перемещение только построек 1×1. Каталог уже содержит размер 1×1 для всех игровых типов; его данные не менялись.

Существующие записи с `footprint_w` или `footprint_h` больше единицы остаются в базе без автоматического изменения. Их полная площадь по-прежнему учитывается при чтении карты и проверке занятости. Такие постройки нельзя улучшать или перемещать до отдельного переноса данных. Обычное обновление их состояния сохраняет прежний размер.

Клиент проверяет новое размещение как 1×1, показывает контур одной клетки и не открывает режим переноса исторической многоклеточной постройки на карте. В меню строительства и макете убрана строка размера; профильные клиентские тесты нового поведения прошли.

Пункт 11 выполнен частично: незакоммиченные внешние изменения `Inspector.tsx` и `FirstCityHelp.tsx` убирают строки размера, но их происхождение ещё не установлено. Внешний Inspector по-прежнему предлагает перенос и поворот исторической многоклеточной постройки; сервер отклоняет оба запроса. Требуется безопасно интегрировать этот UI и провести общую проверку игры. Исторические записи следует отдельно инвентаризировать и переносить только с проверкой пересечений на карте.
