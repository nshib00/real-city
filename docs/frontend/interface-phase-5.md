# Фаза 5: адаптивность и управление

Актуализация 31.10.2026: блокировка Chromium снята. Актуальные проверки, снимки и ограничения — в [браузерной приёмке](interface-browser-review.md), статусы — в [плане](../plans/interface-redesign-plan.md). Ниже сохранён первоначальный срез реализации.

Реализованы мобильное раскрытие инспектора, сохранение выделения при сворачивании, возврат фокуса, последовательный маршрут F6/Shift+F6 и ссылки перехода. Меню строительства фокусируется при открытии и возвращает фокус при закрытии. Escape обрабатывается внутри панели, прежде чем достигнет глобальных команд.

Добавлены кнопки перемещения и масштаба карты, стрелки и +/- для фокуса на карте; движение камеры обновляет существующий viewport и загрузку чанков. Однопальцевое перемещение использует Pointer Events, отмена/уход указателя завершают движение. Клик после движения более 8 px не доходит до выбора/строительства. Pinch страницы и Ctrl/Command-wheel разрешены; собственный жест масштаба мира не добавлен, для него есть кнопки.

Файл `responsive-controls.css` импортируется после прежних стилей. Он разделяет нижние панели, задаёт touch-цели, перенос длинных подписей, прокрутку ресурсов, видимый фокус, safe area и размеры панелей по Visual Viewport API. Фиксированные высоты содержимого заменены ограничением и прокруткой. Шрифт, серверная логика и контракты сохранены.
