## Запуск стенда и снимков

Из `frontend/`:

```bash
node node_modules/playwright/cli.js install chromium
npm run dev -- --host 127.0.0.1 --strictPort
# В браузере: http://127.0.0.1:5173/design.html
```

Остановить ручной dev-сервер перед автоматическим запуском:

```bash
node node_modules/playwright/cli.js test -c playwright.design.config.ts --list
node node_modules/playwright/cli.js test -c playwright.design.config.ts
node node_modules/playwright/cli.js test -c playwright.interface.config.ts
node node_modules/playwright/cli.js test -c playwright.review.config.ts
```

Конфигурация задаёт четыре размера: 1440×900, 1024×768, 390×844, 320×700, DPR 1, русский язык, UTC, reduced motion, один worker. В тестах фиксирована дата 30.10.2026 12:00 UTC. `components.spec.ts` проверяет DOM, клик, disabled, повтор, обе CSS-переменные шрифта, изменение viewport и снимок. `baseline.spec.ts` открывает настоящий App с изолированными API/WS-фикстурами; неизвестные запросы и ошибки страницы приводят к провалу, без обращения к реальному аккаунту. Это исходный пустой город, не полный набор игровых состояний и не live-server E2E.

Снимки создаются раздельно в `frontend/design-results/`, `frontend/interface-results/`, `frontend/review-results/` через `testInfo.outputPath`. Проверенные снимки сохраняются в `docs/assets/ui/`. Неизвестные API-запросы не заменяются общим `{}`. Системный Chromium выбирается через общий `playwright.browser.ts`; другой путь можно задать переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. На машине без системного браузера остаётся стандартный браузер Playwright. Локально используется аппаратный ANGLE/Mesa, в CI — SwiftShader; выбор задаётся PLAYWRIGHT_GL_BACKEND. Снимки не заменяют сравнение производительности до/после.

## Экспорт ассетов

Из корня проекта:

```bash
blender --background --threads 2 --python tools/assets/ui/export_pilot.py -- frontend/public/assets/ui/pilot
python tools/assets/ui/check_pilot.py
```

`tools/assets/ui/select.svg` — оригинальный вектор выбора клетки; скрипт проверяет разрешённые элементы/атрибуты, viewBox и лимит 2 KiB и копирует его в публичный каталог. В SVG нет шрифтов, внешних ссылок, скриптов или embedded raster. Миниатюра камня создана программной Blender-сценой из двух гранёных объёмов, фиксированной ортокамерой и мягким верхним светом; исходник — `export_pilot.py`, локальный `.blend` восстанавливается из него. PNG: 64×64 RGBA, прозрачный фон, поля, бюджет 16 KiB. Массовый набор пока не заменён. Предпросмотр — раздел пилотных ассетов на стенде.

Пилотный PNG осмотрен: два читаемых гранёных камня, прозрачность, объект не обрезан. Blender сообщил несовместимость системного OCIO 2.4.2 с конфигурацией 2.5 и применил fallback. Геометрия/экспорт проверены, финальное согласование цвета с миром требует исправленного OCIO; не использовать этот рендер как эталон финальной палитры.
