# Фаза 7 — ассеты интерфейса

Актуализация 31.10.2026: блокировка Chromium снята. Актуальные проверки, снимки и ограничения — в [браузерной приёмке](interface-browser-review.md), статусы — в [плане](../plans/interface-redesign-plan.md). Ниже сохранён первоначальный срез реализации.

Создан оригинальный набор: 55 функциональных знаков, 80 ресурсных миниатюр и два орнамента. Шрифт, игровые 3D-модели и серверные правила сохранены.

## Подключение

Прямые импорты Lucide заменены собственными рисунками в HUD, инструментах, категориях строительства, инспекторе, профиле, союзе, журнале, уведомлениях, настройках и общих компонентах. Ремонт использует скобу и ключ, строительство — фундамент с крышей, атака — прицел с направлением удара. Молоток остаётся знаком ремесла/улучшений.

`AeolianIcon` использует встроенные пути и `currentColor`; запросов для функциональных знаков нет. По умолчанию знак декоративный, `label` включает смысловой режим. Неизвестный ключ получает shortage. Active/disabled/focus принадлежат кнопке; ожидание показывает часы без обязательной анимации. Подписи и причины действий сохранены.

`ResourceIcon` использует SVG нового каталога с фиксированной ревизией URL и явными размерами. Поле миниатюр 32×32, прозрачный фон, общий масштаб и плоская предметная стилизация. Материалы сохраняют цвет; родственные предметы отличаются конструкцией. Контейнер ≤20 px включает встроенный монохромный знак. Ошибка загрузки оставляет название и встроенный fallback; неизвестный id не подставляется в путь. Старые PNG/GLB сохранены для исходников и игровых потребителей.

`craft.svg` использует дерево/камень, `technology.svg` — латунь/стекло/светокристалл. Диалоги и Drawer используют ремесленный вариант; `data-ui-era="technology"` выбирает технологичный. Каркас и размер орнамента одинаковы. Автоматического вывода эпохи из уровня игрока нет: UI пока не использует отдельное серверное поле эпохи.

## Воспроизведение

Из корня проекта:

```bash
python tools/assets/ui/build_icon_set.py
python tools/assets/ui/build_resource_icons.py
python tools/assets/ui/build_icon_manifest.py
python tools/assets/ui/export_icon_review.py
```

Первые три команды используют стандартную библиотеку Python; экспорт требует установленных ImageMagick и Pillow. [Реестр](../art/ui-icon-manifest.md), [пилот](../assets/ui/review/icons/pilot.png), [ресурсы](../assets/ui/review/icons/resources.png), [лист размеров и фонов](../assets/ui/review/icons/index.html). Пилот и пример ресурса экспортированы в прозрачные PNG и lossless WebP. В runtime используются SVG; растровый атлас для такого объёма не нужен. Ресурсные URL допускают повторное использование браузерного кеша; production-заголовки кеширования здесь не проверялись.

## Проверки

`assets:ui`, включённый в `assets:budget`, проверяет покрытие каталога, декларативную структуру SVG без ссылок/CSS/событий/шрифтов, дубли функциональных SVG и отсутствие прямых импортов прежнего набора. Лимиты: 4 КБ на SVG и 128 КБ суммарно. Новый набор: 38.9 КБ. Общий бюджет также проходит.

343 теста в 84 файлах прошли, включая доступные имена, fallback и новые URL HUD/инспектора. Сборка и lint прошли. Листы пилота и миниатюр просмотрены как изображения, не как снимки игры.

## Открытая приёмка

Vite не смог открыть `127.0.0.1:5173`: `listen EPERM`. Реальные снимки UI на траве, воде, руинах и зданиях, DPR 1/2, масштаб 100/200%, симуляции цветового зрения и узнавание без подписей остаются открытыми. Также не закрыты отдельная оптическая геометрия каждого функционального знака для 16 px и полный набор сочетаний владения/редкости/угроз. Не заменять эти проверки листами ассетов.
