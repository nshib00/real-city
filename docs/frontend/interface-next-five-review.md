# Проверка следующих пяти пунктов редизайна

31.10.2026. Объём: 1Б.7, 3.4, 6.3, 7А.2, 7А.5. Шрифт и серверные игровые правила сохранены.

## Вход и первый цикл — 1Б.7

Vite `127.0.0.1:5177`, proxy на `127.0.0.1:18080`, живой backend из локального образа `real-city-test-backend:latest`. Для изоляции запущен контейнер `real-city-design-check`, APP_ENV=test, хранение в памяти. Чужие аккаунты и базы не менялись. Ранее работавший тестовый стек исчез во время проверки; недоступность API воспроизвела реальную ошибку формы, значения сохранились.

Пройдено в Chromium: регистрация тестового аккаунта, настоящий Pixi canvas, WebSocket connected, выбор свободной клетки через координаты, обычная кнопка строительства бесплатной ратуши. Сервер вернул активную постройку, помощь исчезла. Reload возвращает на карту. При временном 503 проверки сессии токен сохраняется и доступен повтор. Снимки: `docs/assets/ui/review/start/`.

Исправлены proxy WebSocket (`ws: true`), высота/смещение visualViewport и прокрутка активного поля. Добавлены действующие ограничения имени города и русский перевод известных ошибок полей. Сервер принимает латинские буквы, цифры, пробел, дефис и подчёркивание; доменная валидация не менялась.

**Остаток:** настоящая клавиатура Android/iOS на физическом устройстве не проверена. Уменьшенный viewport и события visualViewport не заменяют её. Пункт 1Б.7 остаётся частичным. Сбой проверки сессии моделировался маршрутом браузера; успешные auth/строительство/WS выполнялись настоящим сервером. Перезапуск backend с сохранением данных в этот сценарий не входит.

## Занятые территории — 3.4

API не задаёт границы контроля пустой земли. `occupiedTerritory` строит зоны строго по загруженным зданиям, владельцам и серверным footprint. Соседние клетки одного владельца объединяются внешним контуром; разные владельцы, даже союзные, разделяются. Руины исключены, замыкание мира учтено. Радиус влияния и права на соседние ресурсы не выдумываются.

Один расчёт применяется в Pixi и SVG карты мира. Свой контур сплошной, союзный штриховой, чужой точечный; подложка сохраняет читаемость над местностью. Границы вынесены над спрайтами, чтобы основание здания их не скрывало. Легенда объясняет смысл и ограничение загруженной области. Нейтральные узлы и угрозы имеют отдельные знаки. Unit-тесты проверяют смежность, владельцев, размеры и шов мира.

## Движение — 6.3

`motionPolicy` объединяет выключатель эффектов и prefers-reduced-motion: любой запрет имеет приоритет. При запрете Pixi не обновляет циклические оверлеи зданий и кадры монстров каждый тик. Новые серверные объекты, HP и координаты продолжают вызывать перерисовку; монстр получает актуальную клетку без интерполяции и статичный кадр текущего действия. Отключено покачивание fallback огонька. Настройка/media query вызывают немедленную перерисовку, слушатели очищаются при размонтировании.

Таймеры производства и симуляция не останавливаются. Three-превью рисуется по change/resize, без RAF, AnimationMixer и автоматического вращения; damping и autoRotate явно выключены, ручное управление сохранено.

## Оптика и бейджи — 7А.2, 7А.5

64 функциональных знака имеют отдельные SVG и TypeScript-рисунки 16×16. Основная сетка 24×24, поле 20×20, линия 1.8 px; малая сетка имеет поле 12×12 и линию 1.5 px. Исключения оптического выхода и экспорт: `frontend/public/assets/ui/icons/source/README.md`. Бюджет обоих наборов вместе с 80 ресурсами и двумя орнаментами: 54.4/128 KiB. Генератор проверяет совпадение ключей малого и основного набора.

Добавлены знаки строительства, готовности, истощения и редкого ресурса. Владение, категория, угроза, состояние, редкость и выбор расположены рядом, основной рисунок не перекрывается. Редкость берётся только из существующей категории rare; новые игровые уровни не введены. Потребители — инспектор и реестр.

Стенд `/design.html`: раскрываемые «Матрица бейджей» и «Оптические варианты иконок». 384 комбинации бейджей, 192 карточки иконок на светлом, тёмном и сером фоне. Проверено отсутствие переполнения карточек, включая ширину 320 px. Листы просмотрены агентом; независимое ревью остаётся в 8.3.
