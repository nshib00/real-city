# Фаза 1А — палитра, токены и обозначения

31.10.2026 выполнены 1А.1–1А.4; сохранение шрифта 1А.5 подтверждено повторно. Выбрана палитра «мастерская Эолии»: непрозрачный пергамент и светлый камень, тёмные текст/каркас, лесной зелёный основного действия, латунь декора, аметист технологий. Классическая тема сохранена для сравнения и отката; настройка «Оформление → Эолия» включает новую. Смена темы не перемонтирует игру и не меняет данные, авторизацию, стоимость или правила действий.

## Сравнение

`playwright.palette.config.ts` проверяет одну и ту же сцену на траве, воде, камне, лесу и руинах. Для обоих вариантов сохранены дневное и затемнённое представления карты. Затемнение — диагностический `brightness(.4)` только canvas, не игровая смена времени суток. Desktop 1440×900 и mobile 390×844: 40 парных кадров, 10 сценариев. Светлые непрозрачные панели сохраняют чтение над всеми пятью поверхностями; тёмная классическая тема сильнее сливается с лесом и ночным фоном. Основная карта и цвет материалов ресурсов не перекрашены.

Материалы: `docs/assets/ui/concepts/palette/`. Примеры: [классическая](../assets/ui/concepts/palette/desktop-grass-classic-day.png), [новая](../assets/ui/concepts/palette/desktop-grass-aeolian-day.png), [новая над тёмной картой](../assets/ui/concepts/palette/desktop-grass-aeolian-dark.png). Изменение гарнитуры не использовано: обе CSS-переменные сохраняют Trebuchet MS / Segoe UI / системный fallback в прежнем порядке.

## Три слоя токенов

`tokens.css` содержит primitive `--ref-*`, семантические `--surface-*`, `--text-*`, `--state-*`, `--action-*` и компонентные `--control-*`. Совместимые `--color-*` продолжают работать. Новая тема переопределяет семантику; `control-states.css` применяет явные background/foreground/border/icon/focus для default, hover, pressed, disabled, loading, error, selected. Функциональный SVG наследует соответствующий foreground через currentColor. Недоступность обозначается штриховой границей и disabled, ожидание — часами/aria-busy; текст сохраняет читаемость.

Карта использует отдельные `--map-*` и прежние числовые цвета Pixi: изменение цвета текста панели больше не меняет её подсветку. Фокус имеет два контура: тёмный/светлый в новой теме, золотой/тёмный в классической. Латунь не используется как мелкий текст на светлой панели. Цвета ошибки, предупреждения, информации и технологий разделены.

## Владение и состояние

`ObjectMarks` показывает круг с точкой (свой), связанный знак (союзный), ромб (чужой), пустой круг (нейтральный). Угроза — отдельный треугольник, выбор — уголок и подпись. На мини-карте формы не вращаются вместе с прежним маркером категории. В инспекторе отдельные подписи сохраняются одновременно.

Союз определяется только при совпадении group_id профиля с подтверждённым ответом состава союза; неизвестный или другой состав не превращает объект в союзный. Это отображение, а не клиентское разрешение атаки. Нейтральность не приписывается голому тайлу без серверных данных владения. Угроза берётся из состояния монстра или недавнего события урона, а не из низкого здоровья само по себе.

Матрица содержит 4 типа владения × 4 сочетания состояния × 3 окружения (светлое/тёмное/без цвета). [Лист](../assets/ui/concepts/palette/desktop-aeolian-ownership.png). Формы, подписи и расположение сохраняют смысл без цвета. Полная система редкости/всех бейджей остаётся в 7А.5; визуализация территорий — в 3.4.

## Приёмка

12 браузерных проверок палитр/матрицы прошли, отдельно проверены hover/pressed/focus и ошибка ввода в обеих темах. Расширенный UI-набор новой темы: 25 успешных сценариев с DPR 1/2, текстом 200%, симуляциями цветового зрения, fallback, своими/чужими объектами и offline; 23 неподходящие комбинации проектов пропущены намеренно. Аудит computed colors/alpha проходит для текущих видимых состояний; подпись уровня и диагностические строки исправлены по результату сравнения.

Аудит не является сертификацией всех будущих игровых состояний, экранным диктором или пользовательским исследованием. Исходные пиктограммы расширены пятью знаками (60 функциональных иконок, 80 ресурсов, два орнамента; 39.9 КБ / 128 КБ). Новые шрифты и runtime-зависимости не добавлены.

Дополнительно прошли 376 unit-тестов в 95 файлах, 16 проверок дизайн-стенда и четыре проверки auth с новой темой. Для обеих тем вычислены пары всех семи состояний: текст ≥4.5:1, границы/иконки ≥3:1, хотя бы один контур двойного фокуса ≥3:1; JSON сохранён рядом со снимками. Эталонные снимки стенда обновлены под добавленные поля и переключатель темы.

Из `frontend/`: `npm run test:e2e -- --config playwright.palette.config.ts`. Новая тема полного ревью: `REAL_CITY_REVIEW_THEME=aeolian npm run test:ui-review -- --output=../output/playwright/aeolian-review`.
