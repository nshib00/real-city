# Проверка живого API

После запуска backend с применёнными миграциями выполните из корня проекта:

```bash
REAL_CITY_API_URL=http://127.0.0.1:18080 python3 tests/e2e/api/smoke.py
```

Сценарий создаёт двух игроков с ратушами рядом, проверяет повтор запроса с тем же `Idempotency-Key` после обновления токена, чтение инвентаря и монстров, запуск и завершение рейда с уроном, а также HTTP upgrade WebSocket. Полный проход занимает около 30–40 секунд из-за задержки рейда.
