# Производственные здания

Здесь лежат runtime-модели производственных построек Real City.

Общие требования:

- `.blend` сохраняется рядом с экспортами;
- `.glb` экспортируется для общего набора и для каждого состояния;
- состояния: `active`, `construction`, `damaged`;
- origin в центре основания 1x1/footprint тайла;
- материалы именуются по роли и читаются в изометрии.

Доступные семейства:

- `lumber_yard` - Blender-ассеты лесопильного двора;
- `sand_quarry` - процедурные GLB/PNG ассеты Песчаного карьера для уровней 1-3.
