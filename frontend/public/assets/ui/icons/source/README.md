# Геометрия иконок Эолии

Канонический редактируемый источник: `tools/assets/ui/build_icon_set.py`, словари `PATHS` и `SMALL`. Генерация из корня: `python tools/assets/ui/build_icon_set.py`. Знаки оригинальные; лицензия MIT. Выход: SVG 24×24, отдельные SVG 16×16 в `small/`, реестры TypeScript и manifest.

Основная сетка 24×24, рабочее поле 20×20 (2…22), линия 1.8 px, bevel-соединение и круглые окончания. Допустимый оптический выход до 1 px для вершин, направлений и наружного контура: `build`, `road`, `production`, `sound`, `mute`. Знак не касается границы SVG с учётом половины линии. Центральная ось x=12; у направленных знаков балансируется видимая масса, а не bounding box.

Малая сетка 16×16 — собственный рисунок, поле 2…14, линия 1.5 px. Убираются вторичные насечки, окна, внутренние грани и дублирующие линии. Не уменьшать сложный 24 px SVG вместо выбора малого варианта. `AeolianIcon` выбирает малую геометрию при числовом размере ≤16. Размер кнопки остаётся независимым от размера рисунка.

Проверка масштаба и оптики: `/design.html`, раздел «Оптические варианты иконок» — 16/20/24/32 px на светлом, тёмном и сером фоне. Стенд использует настоящие компоненты; независимая человеческая приёмка всех экранов остаётся в 7А.9/8.3.
