# Рецепты звуков

`pilot.json` содержит шесть пилотных `sound_id`, по два кандидата `a`/`b` и 2–3 варианта каждого. `seed` и порядок слоёв закреплены: одинаковая команда создаёт одинаковые PCM-данные. Слои используют `sine`, `triangle`, `noise`, ADSR `[attack, decay, sustain, release]`, `frequency`, `sweep` в Гц/с, `lowpass` и короткое `echo`. Варианты меняют высоту примерно на ±3–7%, атаку и фактуру шума. Кандидат `a` сейчас служит техническим вариантом по умолчанию; художественный выбор фиксируется после слепого прослушивания.

Рецепт добавлять только вместе с записью происхождения в `docs/audio/asset-register.md`. Имена `sound_id` должны совпадать со словарём `frontend/src/audio/soundEvents.ts`.
