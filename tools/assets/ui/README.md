# Пилот экспорта интерфейсных ассетов

Оригинальные исходники проекта, созданные 30.10.2026 для проверки цепочки экспорта фазы 0. Внешние изображения и наборы иконок не использованы. Это технический пилот, не утверждённый полный набор фазы 7А.

- `select.svg` — функциональный знак выбора клетки, 24×24, currentColor, без шрифтов и внешних зависимостей.
- `export_pilot.py` — воспроизводимая Blender-сцена камней, камера, свет и PNG-экспорт; локальный `stone.blend` генерируется и не обязателен в Git.
- `check_pilot.py` — проверка безопасной структуры SVG, размеров, прозрачности, полей и бюджета PNG; копирование SVG в публичный каталог.

Команды, ограничения OCIO и браузерного предпросмотра: [инструменты дизайна](../../../docs/frontend/design-tooling.md). Выход: `frontend/public/assets/ui/pilot/`, используется только на dev-стенде.
