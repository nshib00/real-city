# Стартовая диорама Blender

`start-city.blend` собирает изометрический фрагмент карты из существующих Real City моделей `town_hall_l01_active_LOD0.glb` и `villa_l01_active_LOD0.glb`, оригинальных тайлов местности, каменной дороги, грядок и деревьев. Исходные модели принадлежат этому репозиторию и сохраняют свои игровые ассеты/описания; внешняя геометрия не импортировалась.

`start-city-render.png` — контрольный Blender-рендер. Публичные размеры WebP готовятся экспортёром в `frontend/public/assets/ui/start/`. Камера, коллекции и материалы находятся в `.blend`; экспортированная сцена статичная и не создаёт WebGL-контекст до входа.

Пересборка: `python3 tools/assets/ui/build_start_scene.py`.
