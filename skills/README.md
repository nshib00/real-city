# Навыки проекта

Навыки для Blender хранятся в `blender-skills/`; навыки интерфейса — в `frontend-design/` и `game-ui-design/`.

| Навык | Назначение | Источник и лицензия |
|---|---|---|
| `frontend-design` | Авторский визуальный язык веб-интерфейса, типографика, композиция, проверка макетов | [Anthropic skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design), Apache-2.0; текст лицензии в `frontend-design/LICENSE.txt` |
| `game-ui-design` | HUD, сценарии игрока, состояния, навигация, доступность и проверка игрового интерфейса | [Jeremy Longworth AgentSkills](https://github.com/jeremylongworth-source/AgentSkills/tree/main/skills/game-ui-design), MIT; текст лицензии в `game-ui-design/LICENSE` |

Оба внешних навыка загружены без изменений 18.10.2026. Для задач Real City применять их вместе с `requirements/design-and-visual-style.md`, `docs/game-design/visual-style-and-setting-options.md` и `docs/art/visual-style-guide.md`; требования проекта имеют приоритет.
